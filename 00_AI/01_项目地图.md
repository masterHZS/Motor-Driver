## 1. 系统链路（先建立这个心智模型）

**当前主线（实板）**

```text
HostSoftware（Qt6/QML，Modbus-RTU 主站）
  → USB-TTL / DAPLink 虚拟串口，9600-8N1，从站地址 1
  → 外接 HC32F072JATA（02_固件/F072_MotorCtrl，-Direct 模式）
  → 六路栅极信号 PB2/PA7/PA4/PB0/PB12/PB1 → V3.1 测试点 TP12–TP17
  → V3.1 板载 FD6288T 栅驱动 → 三相 MOSFET 功率级
  → 2216-730KV 三相无刷电机（4S，12.0–16.8 V）
```

**历史链路（保留参考，勿按它接线）**

```text
HostSoftware → DAPLink → 板上 HC32F005 UART0 → 20 kHz PWM → 功率级     ← F005 已拆，仅留固件
HostSoftware → F072_Bridge → 第二颗 F072 级联 → 功率级                  ← 旧级联方案
```

三段式理解本板：**功率级 + 栅驱动（FD6288T）+ 采样网络** 在板上；
**主控**当前在板外（F072）；板上 MCU 位 `U5` 是空位。

## 6. AI 的默认工作流建议

1. 读 `02_当前状态.md`，确认「当前主线」与「禁止事项」。
2. 按主题用第 2/3 节的表定位权威文件，用 `rg -n` 定点读，不要全目录遍历。
3. 需要改设计/固件时：先看权威文件 → 再改 → 再按 `04_构建烧录命令.md` 验证。
4. 有新结论：追加到对应权威文件，并同步 `02_当前状态.md`（若状态变了）。

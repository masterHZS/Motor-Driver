## 3. 当前主链路与接线（照此执行）

```text
HostSoftware → DAPLink 虚拟串口（9600-8N1，从站 1）→ 外接 F072_MotorCtrl（-Direct / -BEMF）
  → PB2/PA7/PA4/PB0/PB12/PB1 → V3.1 TP12/TP13/TP14/TP15/TP16/TP17 → FD6288T → 电机
```

| F072 | V3.1 测试点 | FD6288T | 功能 |
|---|---|---|---|
| PB2 | TP12 `PWM_AH` | HIN1 | A 相高边 |
| PA7 | TP13 `PWM_AL` | LIN1 | A 相低边 |
| PA4 | TP14 `PWM_BH` | HIN2 | B 相高边 |
| PB0 | TP15 `PWM_BL` | LIN2 | B 相低边 |
| PB12 | TP16 `PWM_CH` | HIN3 | C 相高边 |
| PB1 | TP17 `PWM_CL` | LIN3 | C 相低边 |
| GND | TP2 `AGND`（TP19才是`PGND`） | COM在PGND | 两地经R47连接，必须核对地电位差 |

- F072 由自己的 USB/5 V 供电，**只接六路信号 + GND**。
- 六路信号线尽量短，远离三相输出与自举节点。
- PC 串口：DAPLink TX → PA10，RX → PA9，GND 共地。

## 4. 寄存器接口（F005 与 F072 通用映射）

| 地址 | R/W | 含义 |
|---|---|---|
| `0x0000` | R | 运行状态（1 运行 / 0 停止或故障） |
| `0x0001` | R/W | 启停请求（**写 0 = 六路立即拉低**） |
| `0x0002` | R/W | 目标油门0–100；**当前F072需另写0x0001=1，非零油门不会隐式启动** |
| `0x0003` | R/W | PWM 频率（F005 仅接受 20000 Hz；F072 1000–20000 Hz） |
| `0x0004` | R | 实际占空比（F072 上限 30%，BEMF 版上限 15%） |
| `0x0005` | R | 故障位（0x0001 非法命令，0x0002 通信超时，0x0004 BEMF 丢失） |
| `0x0006` | R | 当前电换相频率 Hz |
| `0x0007` | R | 固件版本（F072 = `0x0100`） |
| `0x0008` / `0x0009` | R | 通信错误 / 成功计数 |

通信超过 **1 秒**无有效请求 → 立即关断六路并置故障。

## 6. 已知风险与安全约束（每次上电前过一遍）

1. **必须限流**：12.0–16.8 V / 5 A（首转建议 14.5–15.0 V），低油门起步；有条件先断开电机看六路波形。
2. **禁止开环带电机**。
3. 外接F072 **不读** `AIN_VBUS`/`AIN_ISENSE` → **没有软件欠压/过流保护**；FD6288T手册确认UVLO/防直通，**不能将商品信息中的SCP当作电机过流兜底**，见其知识库§7。
4. 3.3 V 轨负载必须 **≤ 30 mA**（`U4` 压差 8.775 V 全变热：30 mA ≈ 74 ℃，100 mA ≈ 129 ℃ 超限）。
5. 自举电容 `C5/C6/C7 = 470 nF` 只够 64–77 个开关周期 → **低边必须每个 PWM 周期都开关**（互补驱动 + 硬件死区）：「高边 PWM + 低边常通」会让高边掉压。
6. 板上**无VC硬件刹车**；原F005的软件限流设计不代表当前外接F072已实现，外接配置必须依赖限流电源。
7. **不用外部晶振**，用内部 RCH 24 MHz；换相靠「过零事件 + 定时器延时」自同步，±2.5% 只影响转速读数。

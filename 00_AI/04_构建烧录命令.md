## 1. PCB：重新生成原理图 / 网表 / BOM / 渲染

```powershell
cd ".\01_PCB\Motor-project"          # 必须在工程根执行，脚本内部用相对路径
node "_生成器_V3.1\check-design.mjs"                                   # 电气自检（含封装白名单硬拦截）
node "_生成器_V3.1\build.mjs"                                          # 出图 + 端到端校验 + 网表/BOM +（自动）重出 ERC 与官方网表
node "_生成器_V3.1\render.mjs"                                         # 渲染 SVG
node "_生成器_V3.1\raster.mjs" "motor-driver-V3.1.svg" "motor-driver-V3.1.png" 2000   # SVG → PNG
node "_生成器_V3.1\check-wires.mjs"                                    # 走线体检（排查 pin_not_connected）
```

**验收标准**：`build.mjs` 结尾的 ERC 必须是 **Errors 0**（出现 error 会让构建失败）；生成的 `.kicad_sch` 已由脚本独立重新解析并做过端到端校验。

**只改设计**：改 `_生成器_V3.1/design.mjs`（单一数据源），然后重跑上面三步。

## 2. 固件：外接 F072（当前主用）

```powershell
cd ".\02_固件\F072_MotorCtrl"

.\build.ps1 -Direct            # 直连上位机模式（UART0 PA9/PA10, 9600-8N1）—— 默认当前方案
.\build.ps1 -Direct -Flash     # 编译 + pyOCD 烧录
.\build.ps1 -BEMF -Direct      # BEMF 闭环版本（带电机必须用这个）
.\build.ps1 -Clean             # 清理构建产物
```

可选参数：`-DirectBaud 9600`、`-ToolchainBin "<gcc bin>"`。

产物：`build/hc32f072.elf`、`build/hc32f072.hex`、`build/hc32f072.bin`。

- 不传 `-Direct` = 旧的 cascade 模式（UART1 PA2 单线半双工 115200，配合 `F072_Bridge`）。
- `-BEMF` 会**替换** `motor.c` 而编译 `user/motor_bemf.c`（两者互斥）。
- 协议回归：`python .\tests\test_protocol_vectors.py`。

同名 `Makefile` 也可用（`make`），但 Windows 上推荐 `build.ps1`。

## 3. 固件：板上 F005（已拆板，保留参考）

```powershell
cd ".\02_固件\F005_Slave"

.\build_comms.ps1                 # 默认 -Direct 1：UART 9600，0x0002 直控占空比
.\build_comms.ps1 -Flash          # 编译 + 烧录
.\build_comms.ps1 -Direct 0       # 旧的传感器版（无感）配置
```

产物：`build_comms/comms.hex`（+ `.elf` `.bin`）。主要可调参数：

| 参数 | 默认 | 含义 |
|---|---|---|
| `-MaxDuty` | `25` | 占空比上限 % |
| `-MinVbusMv` | `13000` | 欠压门限 mV（⚠️ 与母线窗口不匹配，见 `02_当前状态.md` §5） |
| `-SwdReleaseMs` | `5000` | 复位后保持 SWD 的时间（保护唯一烧录口） |
| `-DirectMinHz` / `-DirectMaxHz` | `10` / `120` | 开环电换相范围 Hz |

**SWD 被锁死时的恢复烧录**（P27 已切到 UART，`pyocd flash` 报 `No ACK`）：

```powershell
.\flash_under_reset.ps1 -Image .\build_comms\comms.hex    # 先拉 nRESET 连接并 halt，再正常烧录
```

## 5. 串口与协议（上位机 ↔ 主控）

| 参数 | 值 |
|---|---|
| 波特率 / 格式 | **9600-8N1**（界面里波特率与数据位固定） |
| Modbus-RTU 从站地址 | `1` |
| 功能码 | `0x03` 读保持寄存器、`0x06` 写单寄存器 |
| 轮询 | 250 ms 读 `0x0000–0x0009`；应答超时 500 ms |
| 通信中断保护 | 从机侧 1 秒无有效请求 → 关断六路输出并置故障 |

帧示例：

```text
读状态:  01 03 00 00 00 0A C5 CD
启动:    01 06 00 01 00 01 19 CA
停止:    01 06 00 01 00 00 D8 0A
油门50:  01 06 00 02 00 32 A9 DF
油门80:  01 06 00 02 00 50 28 36
```

## 7. 每次上电 / 带载前的检查清单

1. 限流电源：12.0–16.8 V，限流 5 A（首转 14.5–15.0 V），低油门起步。
2. 确认用的是 **BEMF 闭环固件**（开环禁止带电机）。
3. 有条件先断开电机，在 TP12–TP17 看六路波形与死区。
4. 先量 **AGND↔PGND 之间的电压**（`R47` 是单点星接，虚焊过一次），再谈任何数字信号。
5. 3.3 V 轨负载 ≤ 30 mA。

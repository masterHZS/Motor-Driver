## 1. 三条通用教训（先记这三条）

1. **「0 Ω 电阻量出 0 Ω」≠ 它连通了** —— 元件两端永远是 0 Ω，哪怕两个焊点全断。要量**两个焊盘之间**的电压。
2. **先量「两条地之间的电压」，再谈任何数字信号。** 逻辑地（AGND）与功率地（PGND）一旦有偏移，全套 `VIL`/`VIH` 判据作废。
3. **读数「飘」是虚地的指纹** —— 同一节点一会儿 0 V、一会儿 2.795 V，先怀疑参考地，而不是被测点。

## 2. 已发生的三处返修（改版前必看）

| # | 现象 | 根因 | 处置 |
|---|---|---|---|
| 1 | 12 V 轨只有 1.27 V | **`R10` 与 `R11` 贴反**（应 8.66 kΩ / 1 kΩ，实际 10 Ω / 8 kΩ） | 换回 `C325705` / `C2907002` |
| 2 | `U4`(AMS1117-3.3) 异常发热，耗流 0.11 A | `U4` 自耗 110 mA → `P_D = 8.775 × 0.11 = 965 mW` → `Tj ≈ 137 ℃`（超 125 ℃） | **拆 `R52`+`R53`，由 `TP1` 外部灌 3.3 V**；长期换正品 `C6186` |
| 3 | 六路栅极「毫无反应」、万用表 0 V / 2.795 V 之间飘 | **`R47`（0 Ω，AGND↔PGND 单点星接）焊点虚焊** → AGND 抬高 1.45 V → MCU 只有 1.868 V → 逻辑低 = 1.45 V > FD6288T `VIL = 800 mV` → 六路被认成「高」→ interlock 锁死三相 | 补焊 `R47`，全链恢复 |

## 3. 硬约束：采样系数（文档/固件曾写错过一次）

| 项 | 值 |
|---|---|
| 母线分压 | `R30 = 220 kΩ` 上 / `R31 = 10 kΩ` 下，`R48 = 1 kΩ` 串入 ADC（不产生压降） |
| **母线分压比 `k`** | **`10/230 = 0.04348`** |
| **母线固件系数** | **`14.038 mV/count`**（`2.5/4096/0.04348`） |
| ⚠️ 曾错的值 | `10.381 mV/count`（误用相分压 150k/10k 的 0.0588）→ **母线少报 35% → 欠压必然误报** |
| 交叉校验 | `TP11 = 0.598 V` → **13.75 V**，与 `TP18 = 12.76 V` 自洽 ✓ |

> ⚠️ **同板有两套分压，不可混用**：相电压 `150k/10k = 1/16`；母线 `220k/10k = 1/23`。

## 4. 硬约束：自举电容（改版必须保留）

`C5/C6/C7 = 470 nF`、`Qg = 73 nC` → 只够 **64–77 个开关周期**（实测高边只撑 **1.6–3.2 ms**）。

⇒ **低边必须每个 PWM 周期都开关（互补驱动 + 硬件死区）。**
「高边 PWM + 低边常通」的写法会让自举电容亏电 → 高边掉压。

---

## 5. 未闭环：欠压门限 vs 母线窗口

固件 `MOTOR_VBUS_MIN_MV = 13000`，而文档写母线窗口 12.0–16.8 V → **12 V 母线会被判欠压**。
出路（**待用户拍板**）：① 门限降到 11–11.5 V；② 统一改成「有效母线窗口 13.5–16.8 V」。
首转建议 **14.5–15.0 V / 5 A 限流**。

## 6. 四条必须知道的设计妥协（改版会让它们失效）

| # | 妥协 | 后果 / 约束 |
|---|---|---|
| 1 | **只能用 SWD 烧录，不能用 ISP** | ISP 口官方规定 P35+P36，已被母线电流 ADC（P35）与 C 相高边 PWM（P36）占用。⚠️ **应用固件绝不可驱动 P27/P31**，否则唯一烧录通道锁死 —— 板上 F005 就是因此被拆的（板上无 nRESET 可用） |
| 2 | **没有 VC 硬件刹车** | HC32F005 只有 2 个 VC 比较器，8 个可接 VC 的脚全被 PWM / 模拟量占用；换 QFN24 也解决不了（GPIO 同样 16+1）。过流保护 = 软件限流（每 PWM 周期 ≈50 µs 采样）+ FD6288T 自带 SCP |
| 3 | **不用外部晶振** | 引脚不够（P01/P02 已给模拟量），改内部 RCH 24 MHz。换相靠「过零事件 + 定时器延时」自同步；±2.5% 误差只影响转速读数，不影响换相正确性 |
| 4 | **3.3 V 轨负载必须 ≤ 30 mA** | `AMS1117-3.3` 从 12 V 降到 3.3 V，压差 8.775 V 全变热：30 mA ≈ 74 ℃（安全），100 mA ≈ 129 ℃（超限）。任何「在 3.3 V 上外挂东西」的想法都要先复核 |

## 8. 工具链 / 流程坑

| 现象 | 处理 |
|---|---|
| 上位机构建报 `qmlimportscanner` 路径错误 | 工程路径含中文导致；构建脚本已改用 8.3 短路径 |
| 上位机构建提示 CMake 缓存路径不匹配 | 工程曾改名/搬移；脚本会自动检测并清理 `CMakeCache.txt` 后重新配置 |
| `pyocd flash` 报 `No ACK` | 固件已把 P27/P31 切成 UART（SWD 释放）；用 `flash_under_reset.ps1` 在复位下连接 |
| 想用 ISP 省事 | **不行**，P35/P36 已被占用（见 §6.1） |
| 便携 Python 找不到 | 已删除，用系统 Python（已装 pyocd、PyMuPDF 等） |
| 找不到 arm-none-eabi-gcc | 传 `-ToolchainBin`，或设 `ARM_GCC_BIN`，或解压到工程 `.toolchain/` |
| 大数据手册读不动 | 用 `rg -n` 在 `_datasheet/*.txt` 提取件里定位，PDF 只作最终核对 |

## 2. 硬禁令（违反会损坏硬件或造成不可恢复状态）

| # | 禁令 | 原因 |
|---|---|---|
| 1 | ⛔ **禁止用开环固件带电机**。带电机必须走 BEMF 闭环（`F072_MotorCtrl -BEMF`） | 2026-10-08 开环固定斜坡带电机 → **剧烈震动事故**，已明令禁止 |
| 2 | ⛔ **带电机必须限流**：12.0–16.8 V / 限流 5 A，首转建议 14.5–15.0 V，低油门起步 | 外接 F072 **不读** `AIN_VBUS`/`AIN_ISENSE`，此时**没有软件欠压/过流保护** |
| 3 | ⛔ **应用固件绝不可驱动 P27/P31** | 板上唯一 SWD 烧录口；F005 就是这么锁死、最后被拆掉的（板上无 nRESET 可用） |
| 4 | ⛔ **不要把外接 F072 的 3.3 V/5 V 并到 V3.1 的 `VDD_3V3`/`VBUS`**；**12 V 不可接任何 GPIO** | 双电源互灌 / 器件击穿 |
| 5 | ⛔ 改任何硬件（原理图、封装、参数）前，必须读 `01_PCB/说明.md`（4 条设计妥协 + 3 处返修）与 `01_PCB/Motor-project/V3.1_升级说明.md` | 前两版都因忽略约束返修 |
| 6 | ⛔ 元器件封装必须来自**嘉立创官方库**（`器件选型规范.md` 的 R0 白名单，`check-design.mjs` 硬拦截） | 用户硬性要求；不在白名单 → 构建直接失败 |

## 3. 这个文件夹是什么 / 不是什么

**是**：

- AI 进入仓库的**单一入口**，替代「先读 README 再猜」；
- **现状快照**：把散落在 `README.md`、各 `00_索引.md`、`01_PCB/说明.md`、`dev_notes.md` 里的当前状态汇总成一处；
- **权威指针**：告诉你「这个主题的最终依据在哪一行文件里」；
- 可机器读取的 `manifest.json`（分类、关键文件、忽略清单、状态标志）。

**不是**：

- 不是新的设计来源 —— 不复制网表、引脚表、计算书内容；
- 不是历史记录 —— 调试记录、审核报告留在原目录；
- 不是唯一真相 —— 冲突时以权威文件为准，并**顺手修正本文件夹**。

---

## 4. 维护规则

1. **只写"指针 + 状态"**：本文件夹内不出现第二份网表/引脚表/BOM 数据。
2. **状态变化就改 `02_当前状态.md`**：例如主控换回板上、BEMF 联调通过、欠压门限定案。
3. **新踩坑写进 `05_踩坑与硬约束.md` 的对应表**，并在权威文件（`dev_notes.md` / `01_PCB/说明.md`）留详细版。
4. **目录增删改后同步 `01_项目地图.md` 与 `manifest.json`**。
5. 文件命名保持 `两位数字_中文名.md`，与仓库既有风格一致。
6. 本文件夹**不进 `99_归档/`**，也不放构建产物。

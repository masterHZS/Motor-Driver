### R1 的机制性修正（重点）

初版脚号是**从 PDF 文本层按列序号推断**的 —— 表格跨页就整体错位。现在：

```text
node tools/build.mjs guard     # 数据源自检 + 与 KiCad 官方符号库逐脚比对，不一致即失败
  ✓ 64/64 与 KiCad 官方库一致
node tools/_verify-sym.mjs     # 符号内脚号↔引脚名 与数据源一致
node tools/gen-pin-table.mjs   # 02 文档的全脚表由数据源生成，杜绝手改再错
```

**核心认识**：结构自检（连续无重复/括号平衡/能渲染）**一律不构成引脚正确性证据**；
脚号正确性只能由**独立第三方权威逐脚比对**保证。

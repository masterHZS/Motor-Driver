### 1.1 与旧 V3.1 板的关键差异（**不得照搬**）

| 项 | V3.1（HC32 + FD6288T） | 本底板（DRV8323HR） |
|---|---|---|
| 栅驱动 | FD6288T，**自举**（低边必须每周期开关） | DRV8323H，**电荷泵**，支持 100% 占空比 |
| 相电位引出 | 板上分压 **1/23** 进 ADC | **P2 未引出三相电压**，只有 `IOUTA/B/C` 电流信号 |
| 母线分压 | 1/23 | 1/21.4（124 k/4.7 k，系数 0.0365） |
| 硬件刹车 | 板上**无** VC 刹车 | `FAULT` 可进 MCU 定时器刹车（本设计采用） |
| 逻辑电平 | 3.3 V | 3.3 V（同） |

> ⚠️ `P2` 上的 `VBUS` 是**已分压的采样信号**、`IOUTA/B/C` 是**电流信号**，**都不能当三相原始相电位**（计划 §4.1）。

## 2. P2 控制接口逐针表

### 2.1 机械形态

| 项 | 值 | 依据 |
|---|---|---|
| 类型 | **Header 16×2（2×16 = 32 pin）** | 说明书 §5.2/§5.3 |
| 行数 / 列数 | **16 行 × 2 列** | 说明书 §5.3；第 10 页机械图排针孔连通域计数 = **16 行 × 2 列**（`tools/measure/mech_holes.txt`） |
| 栅格 | **2.54 mm** | 机械图标定：相邻行距 22.961 px，16 行跨度 344 px；若为 2.54 mm → 9.0397 px/mm，此时板高 452 px = **50.00 mm**，与标注 50 完全吻合 ✅ |
| 编号方式 | 链路式（row-major）：Pin n / Pin n+1 为**同一行的左右两针** | 说明书行成对列出（1/2、3/4 … 31/32）+ 底板渲染底面丝印逐行核对 |

**编号链方向（🔶 待实物确认，以下为待验证的判读，不作结论）**：底面渲染似乎显示——右列自上而下为 `+5.0V → GND → GND → GND → GND → GND → VREF_3.3V → VBUS → NTC → GND → NC → GND(?) → DRV_EN → INHA → INHB → INHC → GND`，左列对应 `IOUTC → IOUTB → IOUTA → GND → GND → GND → CBUS → FAULT → NC → NC → GND → CAL → INLA → INLB → INLC → GND`，与说明书 §5.3 逐针文字**一致**。渲染图中 `+5.0V` 与另一根 `GND` 是 2×16 里**唯二的方形焊盘**（PCB 上方形焊盘通常即 Pin 1 / Pin 32）。
→ 结论：**Pin 1 在左列靠 +5.0V 一端，Pin 2 在右列同一行**，编号沿链路式推进。

```
   左列(奇)                右列(偶)
   ┌──────┐                ┌──────┐
   │  1   │ +5.0V ─── GND  │  2   │

   │  5   │ GND    ─── IOUTB│  6   │
   │  7   │ GND    ─── IOUTA│  8   │
   │  9   │ GND    ─── VREF_3.3V│10│
   │ 11   │ VBUS   ─── CBUS │ 12   │
   │ 13   │ NTC    ─── FAULT│ 14   │
   │ 15   │ GND    ─── GND  │ 16   │
   │ 17   │ NC     ─── NC   │ 18   │
   │ 19   │ NC     ─── GND  │ 20   │   ← 见 §2.3 第 1 条
   │ 21   │ GND    ─── DRV_EN│22  │   ← 见 §2.3 第 1 条
   │ 23   │ DRV_EN ─── INHA │ 24   │
   │ 25   │ INLA   ─── INHB │ 26   │
   │ 27   │ INLB   ─── INHC │ 28   │

```
（上图**不是**逐针权威，逐针以上表为准；此处只表达「同一行两针成对、编号沿链路推进」的拓扑。）

### 3.5 三相取样线（SHA / SHB / SHC）的接法与机械

| 项 | 方案 | 理由 |
|---|---|---|
| 取样点 | 底板三相输出端子 `SHA(A) / SHB(B) / SHC(C)`（`PH5` 端子区），**从端子相邻的焊盘或端子螺丝下方引线** | 说明书 §5.4：这三处即桥臂中点；**P2 未引出相电压** |
| 控制板侧 | **4 针连接器**：`1 = GND`、`2 = SHA`、`3 = SHB`、`4 = SHC` | 带 GND 便于差分/示波器探头就近参考，且四芯排线可用标准 4P 壳 |
| 线材 | 三根**独立短双绞线**（信号 + GND 各一），长度 ≤ 100 mm；或一根 4 芯屏蔽线 | 该线承载**原始相端电压**（0–VCC + 开关尖峰），绝缘须 ≥ 100 V |
| 走线约束 | 与 PWM/栅极走线保持 ≥ 2 mm 间距；不跨越 `P2` 的 `INHx/INLx`；控制板侧连接器**远离** MCU 晶振与 `VREF+` | 开关节点是主要噪声源（计划 §④） |
| 固定方式 | 🔶 **待定**：① 直接焊在底板端子焊盘上；② 用带线端子的插拔式（JST-XH 4P 压线） | 计划 §5 把「三相取样固定方式」列为未闭合项；需实物看端子是否可再压线 |
| 禁止 | ⛔ 不得接 `P2` 的 NC 脚、不得把相线并在 `IOUTx` 或 `VBUS` 上 | 计划 §4.2 |

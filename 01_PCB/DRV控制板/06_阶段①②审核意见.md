# DRV 控制板阶段①②审核意见

日期：2026-10-15｜审核人：Codex

**结论：阶段②审核不通过，退回修改，暂不进入正式原理图和 PCB。**

本轮审核对象为接口、资源分配、计算书、BOM 草案、生成器数据源及符号库。现有交付只有库包，没有正式原理图和 PCB，因此本意见不是整板电气或布局验收。本轮仅新增本审核文件，未代改设计。

## 一、必须修改的 5 项 P1 问题

### R1：MCU 物理脚号错误，已经进入库生成源

位置：[pins.mjs 第44行起](C:/Users/28572/Desktop/motor-drive/01_PCB/DRV控制板/tools/lib/pins.mjs:44)、[资源分配第149行起](C:/Users/28572/Desktop/motor-drive/01_PCB/DRV控制板/02_系统方案与资源分配.md:149)。

独立对照 DS12589 Rev 6 的 Figure 10 与 Table 12，`pins.mjs` 中 **36/64 个脚号与引脚名不符**。部分例子：

| 物理脚号 | 当前数据源 | 官方定义 |
|---:|---|---|
| 29 | VSSA，准备接地 | **VDDA** |
| 31 | VREF+，准备接电源 | **VSS** |
| 32 | PB12，准备接 VN | **VDD** |
| 42 | PA10 | **PA8** |
| 49 / 50 | PB7 / PC10 | **PA13 / PA14（SWD）** |
| 62 / 63 | VCAP_1 / VCAP_2 | **PB9 / VSS** |
| 64 | VSS，准备接地 | **VDD** |

按此生成原理图会出现真实电源脚接地、地脚接电源，以及 PWM/SWD 错接。该型号没有文中所写的两只外接 VCAP 引脚；“已目视核实”的声明错误。

**修改要求：**重新建立完整 64 脚映射；同时修正资源表、电源去耦、BOM、审查 JSON，重新生成库包。增加与独立官方引脚表的逐脚比对，不能只检查“1–64 连续无重复”。旧库包在修正前不得用于画图。

### R2：AF 与 ADC 能力表错误，资源不足结论需要重做

位置：[资源分配第131行起](C:/Users/28572/Desktop/motor-drive/01_PCB/DRV控制板/02_系统方案与资源分配.md:131)、[PWM汇总第202行起](C:/Users/28572/Desktop/motor-drive/01_PCB/DRV控制板/02_系统方案与资源分配.md:202)。

- PA8/PA9/PA10 的 TIM1_CH1/2/3 是 **AF6**，不是 AF1。
- PB13/PB14 的 TIM1_CH1N/CH2N 是 **AF6**；只有所选 PB15 的 CH3N 是 **AF4**。
- PA6、PB12 的 TIM1_BKIN 是 **AF6**，不是表中的 AF9。
- PC0–PC3 有 ADC1/ADC2 通道；PA3 有 ADC1_IN4。文中“无 ADC”的结论错误，不能据此宣布模拟资源几乎耗尽。

**修改要求：**按 Table 12/13 重做资源分配，再判断内部比较器、同步 ADC 和扩展资源是否可用。另核对 PB4 串口 RX 与 PA10 PWM 的 UCPD 死电池下拉关联，不能宣称二者“零冲突”；若保留，须明确禁用下拉的配置约定。

### R3：输入保护没有成立，不能依赖假设的内部二极管

位置：[计算书第84行起](C:/Users/28572/Desktop/motor-drive/01_PCB/DRV控制板/03_关键器件初选与计算书.md:84)、[BOM第80行](C:/Users/28572/Desktop/motor-drive/01_PCB/DRV控制板/04_物料清单_BOM草案.md:80)。

相端 60 V 经 1/16 分压得到 **3.75 V**，已高于 3.3 V 基准下的 ADC 转换范围；对 PA0–PA2 这类 TT 输入，还超过 3.3+0.3 V 的输入边界。不能以“未达到假设的 4.0 V 内部钳位点”判定安全。DS12589 Table 15 给出的单脚注入额定值是 **−5/0 mA**，不是文中套用的 ±5 mA 正负通用限值。

反灌计算也漏掉分压网络的戴维南电阻；在所用等效模型下，电流不能直接用电压除以 1 kΩ。3.3 V 上加泄放电阻，或只对地加负压钳位，都不自动证明正过压及掉电输入安全。BOM 默认不装外部钳位，尚无完整保护方案。

**修改要求：**给出可落地的正压、负压、掉电保护电路及具体器件，并逐项核对输入电压、注入限制、钳位误差和反灌路径。覆盖相电位/VN，以及底板仍有电时的电流、温度、FAULT、UART 等跨板输入。保护未闭合前删除“已通过”标记。

### R4：BEMF 采样安排无法实现所承诺的同步过零检测

位置：[计算书第140行起](C:/Users/28572/Desktop/motor-drive/01_PCB/DRV控制板/03_关键器件初选与计算书.md:140)、[采样分组第479行起](C:/Users/28572/Desktop/motor-drive/01_PCB/DRV控制板/03_关键器件初选与计算书.md:479)。

1. 所选常规采样时间档没有 **810 周期**；SMPR 最大档为 **640.5 周期**。按文中 42.5 MHz，最大档加 12.5 周期转换约 **15.36 µs**，不是 19.4 µs。现有时序计算依据错误。
2. “每次换相只扫一轮”无法持续观察换相后出现的过零事件；顺序扫四路也不等于浮空相与 VN 同时采样。当前 **PA2 与 PB12 均只接 ADC1**，因此 C 相与 VN 不能通过这组引脚实现双 ADC 同时采样。
3. 文中的 77.6 µs 扫描已超过 20 kHz 的 **50 µs PWM 周期**；能放进一个换相扇区，不代表能放进有效 PWM 平台。
4. 按文中 4.4 kHz 换相频率，一个扇区约 227 µs，理想过零约在 114 µs；“至少屏蔽 3 个 20 kHz PWM 周期”即 **150 µs**，会屏蔽掉目标过零。

**修改要求：**重新分配浮空相/VN 所需 ADC，给出一个 PWM 周期内的触发、采样和转换安排，以及扇区内重复检测和消隐安排。分别计算外部 RC 阶跃恢复与 ADC 采样保持建立，不得把两者当作同一个过程。同步与窗口不成立时应改硬件参数或引脚，不能仅留给固件补救。

### R5：相电流阈值码值算错，可能导致保护点严重偏高

位置：[计算书第264行起](C:/Users/28572/Desktop/motor-drive/01_PCB/DRV控制板/03_关键器件初选与计算书.md:264)。

沿用文中的 20 mV/A、12 bit、3.3 V 条件：

| 示例电流 | 相对零点的正确码差 | 文中码差 |
|---:|---:|---:|
| 8.8 A | **约218码** | 619码 |
| 13 A | **约323码** | 915码 |

915 码实际对应约 **36.9 A**，不能作为 13 A 的判定值。方向符号另按实际接线和 CSA 定义确定。

**修改要求：**统一从 `Δcode = I × 0.02 × 4096 / VREF_ADC` 重算并校验保护示例。8.8 A、13 A 仍是历史设计估算值，不能升级为实测额定或已批准保护阈值。

## 二、同时修正的 2 项 P2 问题

### R6：LDO 电流预算和参考电压关系不正确

位置：[资源分配第85行](C:/Users/28572/Desktop/motor-drive/01_PCB/DRV控制板/02_系统方案与资源分配.md:85)、[计算书第373行起](C:/Users/28572/Desktop/motor-drive/01_PCB/DRV控制板/03_关键器件初选与计算书.md:373)。

LDO 应按 **Iin≈Iout+Iq** 估算，不能按开关电源公式乘 3.3/5 再除以效率。按文中输出峰值 54–55 mA，输入就已不低于该值，还需计入静态电流；“底板取电≤40 mA”不成立。相分压/VN 从相端取电，也不应全部算成 LDO 输出负载。

底板 REF3033 与控制板独立 LDO 不是同一个参考源，“同轨误差一阶抵消”的说明也不成立。应明确 CSA 零点标定及 ADC 基准换算方式。LDO 输出电容稳定性按选定器件手册闭合，不能用通用封装代替审核。

### R7：机械推断与接口示意不能作为已核实结果

位置：[接口图第73行起](C:/Users/28572/Desktop/motor-drive/01_PCB/DRV控制板/01_接口与机械核实.md:73)、[排针定位第159行起](C:/Users/28572/Desktop/motor-drive/01_PCB/DRV控制板/01_接口与机械核实.md:159)。

P2 逐针表与说明书一致，但前面的示意图把 20、22、24–30 等针的信号画错，包括漏掉 CAL、错移 PWM。即使标注“非权威”，也会误导接线和布板，应删除或修正。

原说明书机械图的排针位于板边附近，不能推定为“关于板中线对称”，更不能以此给出 22.19/24.73 mm 的横坐标。用假定的 2.54 mm 栅格标定图像，再由此宣布栅格已核实，属于循环论证；47/50.2 mm 的所谓冲突也尚未成立。

**修改要求：**保留原图明确标注的外形/孔距，撤回未经支持的排针坐标与“已闭合”声明；P2 位置、方向、间距、配合高度仍待原始工程或实物确认。此缺口允许电路方案继续完善，不能据此冻结 PCB。

## 三、验证结果与返工顺序

本轮已复跑 `node tools/build.mjs check`、`node tools/validate-lib.mjs`，两者均通过；但独立官方脚位比较发现 36 处错误。这说明现有检查只能证明数据结构或格式符合预期，**不能证明引脚、电气参数或接线正确**。KiCad 能渲染符号也不构成电气正确性证据。

请 DeepSeek 按以下顺序返工：

1. **先修 R1/R2**：官方脚号与外设资源重新核对，重生成库包，撤销错误的“已核实”状态。
2. **再修 R3/R4**：保护拓扑、同步采样引脚、RC 与有效窗口一起闭合。
3. **修 R5/R6/R7**：重算阈值与供电，修正接口图和机械假设。
4. 同步 01–05 文档、数据源、BOM 和库包后，交回阶段②复审。复审通过前不进入正式原理图/PCB。

本轮尚未完成全部被动器件及晶振的逐料号电气引脚审核；例如自建四脚晶振符号目前把 1/2 定义为振荡端、3/4 定义为地，仍须对照 C70590 对应厂家图纸确认。该项不能用“封装名匹配”代替。正式原理图阶段仍需完整 ERC、独立网表和元件脚号复核。

# tools/measure/ — 说明书与数据手册的像素级测量脚本

**用途**：`01_接口与机械核实.md` 与 `02_系统方案与资源分配.md` 里的每一个数字，都能用这些脚本复算。
**依赖**：`python` + `PyMuPDF`（`pip install pymupdf`）。**不依赖 numpy/PIL**。
**输入**：
- 底板说明书 `C:/Users/28572/Desktop/POWER_DRV8323HR_V1.01_产品说明书.pdf`（10 页，正文 Rev.1.00b2）
- STM32G431 数据手册 `../../06_参考资料/芯片知识库/_datasheet/stm32g431rb.pdf`（DS12589 Rev 6）

| 脚本 | 作用 | 对应结论 |
|---|---|---|
| `01_p2_holes_from_render.py` | 从第 1 页正/反面效果图按颜色分离金色焊盘，输出 P2 的行列中心 | `01_...md` §2.1 / §3.2 |
| `02_mech_header_holes.py` | 第 10 页机械图：环形模板 + 连通域找排针小孔，得到 **16 行 × 2 列**、平均行距 **22.961 px** | `01_...md` §2.1（2×16 与 2.54 mm 栅格的判据） |
| `03_mech_geometry.py` | 同上：安装孔、板框、P2 相对板边尺寸 | `01_...md` §3.1–§3.4（含 47 vs 50.2 mm 冲突） |
| `04_p2_pads_from_render.py` | 底面渲染的 P2 焊盘连通域，核对底面丝印逐行标签 | `01_...md` §2.1（编号链方向） |
| `05_g431_figure10_extract.py` | 数据手册第 46 页 Figure 10（LQFP64）按坐标提取「脚号 ↔ 引脚名」 | `02_...md` §4.1（**已逐脚目视复核**） |
| `06_g431_table12_af.py` | Table 12（PDF 第 51–60 页）解析出每个脚的复用/附加功能 | `02_...md` §4.1 的 AF 列、`D-05`（`PB15 = TIM1_CH3N` AF4） |

## 关键标定（可复算）

```text
机械图排针：16 行，相邻行距 22.961 px
若该栅格 = 2.54 mm  →  1 mm = 9.0397 px
则板高 452 px = 50.00 mm   ← 与图纸标注「50」完全吻合（标定可信）
   板宽 454 px = 50.22 mm   ← 与文字标注「47」冲突 3.2 mm（必须在实物上复核）
```

## 注意

- 这些脚本是**取证用的一次性分析**，不进入构建管线；构建管线只认 `tools/design.config.mjs` 与 `tools/lib/pins.mjs`。
- 输出里的中文在 Windows PowerShell 控制台可能显示为乱码（控制台代码页问题），**属正常现象**，不影响数值。

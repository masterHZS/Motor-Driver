## 3. 相分压比修改（核心）

### 3.1 分压比必须由"60 V 不死"这一条硬约束反推

原文 1/16：`k = 10k/(150k+10k) = 1/16 = 0.0625`。60 V → **3.750 V**。
`VDD+0.3 V = 3.6 V` ⇒ **已越界**，按 Table 52 对 TT_a 的"正注入 = 0 mA"，**这一条不可协商**。

**反推所需分压比**（留 10 % 余量，即 60 V 对应节点 ≤ 3.0 V）：

```
k_max = 3.0 V / 60 V = 1/20
```

再留电阻容差（±1 % + 温漂）与 TVS 钳位抬升的余量，取：

```
选 k = 1/23：  R1 = 220 kΩ  →  k = 10k/(220k+10k) = 0.0434783 = 1/23.00
```

| 校验项 | 计算 | 结果 | 判据 |
|---|---|---|---|
| 60 V 时节点 | `60 × 1/23` | **2.609 V** | < 3.0 V ✅ < 3.6 V ✅ < 4.0 V ✅ |
| 60 V 时 ADC 端 | `2.609 × 10/(10+10)` | **1.304 V** | < 3.3 V ✅ |
| 40 V（底板标称上限） | `40 × 1/23` | **1.739 V** | ✅ |
| 16.8 V（本项目满电） | `16.8 × 1/23` | **0.730 V** | ✅ |
| 节点达 3.3 V 的相端电压 | `3.3 / (1/23)` | **75.9 V** | 余量 **1.27×** |
| 节点达 3.6 V（工作边界）的相端 | `3.6 / (1/23)` | **82.8 V** | 余量 1.38× |
| 节点达 4.0 V（绝对最大）的相端 | `4.0 / (1/23)` | **92.0 V** | 余量 1.53× |

⇒ **全容差全温最坏情况下节点 2.672 V、ADC 端 2.699 V，距 3.3 V 仍有 0.6 V。**

### 3.3 对 ADC 分辨率的影响（必须交代）

| 项 | 1/16（原） | **1/23（新）** | 评价 |
|---|---|---|---|
| ADC 端 LSB | 0.806 mV | 0.806 mV | 不变 |
| **折算到相端的 LSB** | 12.89 mV | **18.53 mV** | 变差 1.44× |
| 每伏相电压的码数 | 77.6 | **54.0** | 变差 1.44× |
| 相端满量程（节点 3.3 V） | 52.8 V | **75.9 V** | ↑ 覆盖 60 V 尖峰 |
| 16.8 V 时码值 | 1304 | **907** | 仍远大于噪声 |
| BEMF 过零判定需要什么 | 只需"跨零符号变化" | 同 | ✅ 够用 |

> **为什么分辨率下降可接受**：BEMF 过零判定比较的是"相通道 vs VN 通道"的**相对符号**，不是绝对值。
> 判决裕度由 ADC 的 TUE（Table 62–64，±4～5 LSB）与 PWM 纹波决定，**18.53 mV/LSB 不构成瓶颈**
> （折算到 ADC 端仅 0.806 mV/LSB，远小于 20 kHz 采样时刻的残余纹波）。
> 若要恢复分辨率，只能靠降低 VREF+（本设计 VREF+ = VDDA = 3.3 V，不可降）或改差分采样（本板不改），**故不采纳**。

> **引脚类型复核依据**：Table 12（DS12589 p.50–61）逐脚 I/O structure 列。

### 4.3 VN 通道的取值与残余失配（由本次分压比改动引出）

VN 网络**必须与相通道共用同一套分压值**，否则"相 vs VN"的比较没有意义。拓扑：

```
  SHA ──R_VN(10k)──┐
  SHB ──R_VN(10k)──┼── V_star ──R1(220k)──┬── Rs(10k) ──┬── PB12 (ADC1_IN11)
  SHC ──R_VN(10k)──┘                       │             │
                                         R2(10k)       C(150pF)
                                           │             │
                                          GND           GND
```

**星形网络的戴维南等效**（三相各 `10 kΩ`）：

```
R_star  = R_VN / 3 = 3.333 kΩ
V_star  = V_avg × R_load/(R_star + R_load),   R_load = R1 + (R2∥Rs) = 220k + 5k = 225 kΩ
```

| 量 | 计算 | 值 |
|---|---|---|
| 星点分压系数 | `225k/(3.333k+225k)` | **0.98540** |
| VN 总增益 `k_vn` | `0.98540 × 10k/(220k+10k)` | **0.042844 = 1/23.34** |
| 相通道 `k` | `10k/(220k+10k)` | **0.043478 = 1/23.00** |
| **增益失配** | `k_vn/k` | **−1.46 %** |
| 60 V 时 ADC 端 | `60 × 0.042844` | **2.5706 V**（相通道 ADC 端 1.304 V） |
| 每相抽取电流 @16.8 V | `16.8/(10k+225k)` | **71.5 µA/相，三相 214 µA**（低于原文 §3.4 的 0.27 mA） |
| 星点等效阻抗对地 | `R_star` | 3.333 kΩ |
| 星点 + 50 pF 线容附加时间常数 | `3.333k × 50 pF` | **0.167 µs**（远小于主时间常数 2.935 µs，可忽略） |
| **时间常数是否匹配** | 两条支路的 `R_th'`（`R1∥R2+Rs = 19.565 kΩ`）与 `C`（150 pF）**完全相同** | ✅ `τ` 严格一致（星点分压只是幅度上的 0.985 系数） |

> **`−1.46 %` 的处置**：折算到 16.8 V 相端是 **246 mV**、40 V 时 584 mV 的等效直流偏置；
> 对过零定时的影响约 **5.8° 电角度（487 Hz 时 ≈ 33 µs）**。**由固件系数修正**（`×1.0148`，可标定）。
> 若希望硬件上消掉：把 `R_VN` 从 `10 kΩ` 降到 `1 kΩ`（失配 −0.15 %，但三相抽取电流升到 2.1 mA，**不划算**），
> 或加 1 % 精度的偏置电阻做配平（**四只电阻配平最多做到 ±0.3 %**，代价是料号增加且引入新的容差源）。
> ⇒ **本设计选"固件系数 + 上电自检标定"**（见 §9.2 U-5）。

### 4.4 为什么相通道**不加**对轨钳位（最关键的设计判断）

审核要求"给出可落地的正压、负压保护"。本节证明：**对相通道，正确的正/负压保护就是分压比 + 串联电阻本身**，加对轨肖特基会**引入新故障模式**。

**(a) 加"肖特基到 3.3 V 轨"（BAV99 / BAT54S 上管）——被否决**

| 问题 | 计算 | 结论 |
|---|---|---|
| 钳位电压 ≠ 3.3 V | `V_clamp = V_rail + V_F`；BAT54S 在 5 mA 时 `V_F ≈ 0.45 V` → **3.75 V** | ⚠️ > 3.6 V（工作边界） |
| 若注入电流更大 | `ΣI_INJ` 允许 −25 mA ⇒ `V_F(25 mA) ≈ 0.55 V` → `V_clamp = 3.85 V` | ⚠️ 逼近 4.0 V 绝对最大 |
| **抬轨** | 该电流灌入 3.3 V 轨，LDO 只吸不灌 ⇒ 轨压升高，**整块 MCU 的 VDD 都超限** | ❌ **危险** |
| 反灌时反而**新增**危险通路 | 掉电时轨 ≈ 0 V，钳位二极管把相端电流直接灌进"死轨" | ❌ 与"掉电保护"目标相反 |
| 本设计是否需要它 | 节点最大 2.672 V（全容差全温）< 3.3 V ⇒ **钳位二极管永不导通**（零收益） | ❌ **不装** |

**(b) 加"齐纳/TVS 到 GND"（3.3 V 齐纳）——被否决**

| 问题 | 计算 | 结论 |
|---|---|---|
| 齐纳拐点软 | BZX84C3V3 在 3.3 V 已有数十 µA 漏电 → 经 `R_th = 9.565 kΩ` 产生 `>0.3 mV` 误差，且**随温度漂移** | ⚠️ 破坏三相一致性 |
| 结电容 | 齐纳结电容 100–400 pF，与 150 pF 滤波电容并联 → 破坏 §3.3 的时间常数匹配 | ⚠️ |
| 收益 | 节点最大 2.672 V，齐纳 3.3 V **永不导通** | ❌ **不装** |

**(c) 加"肖特基到 GND"（负压钳位）——列为备选，默认不装**

判据：**内部 ESD 下二极管在节点低于 −0.7 V 左右才导通**，而节点电压 = `−相端电压 / 23`。
用戴维南算内部二极管的电流（见 §5.2）：相端 −20 V 时只有 **8.7 µA**，相端 −35 V 时 **42 µA**，
**全部远低于 Table 15 / Table 52 的 −5 mA**。负压钳位**没有必要**；加它反而引入：
- 反向漏电（BAT54S 在 25 ℃、`V_R = 2.6 V` 时约 2 µA，高温可达 20–30 µA）经 `R_th` 造成 0.2–0.3 mV 偏置；
- 多 3 只器件与 3 处潜在焊点失效。

⇒ **默认不装**；`04` BOM 中 `D1–D3` 的"BAV99 默认不装"焊盘**可以保留**，但**用途改写为"负压钳位备选"**，
不再声称它是"正压钳位"。若实测相端下冲 < −35 V，才补装（判据见 §7.3）。

**(d) 那么正压靠什么？——靠 TVS + 分压比**

- 分压比把 0–76 V **全部**映射到 0–3.3 V，**不进入注入区**；
- 相线入口装 **SMBJ33A** 挡 ESD / 浪涌 / 感性回馈（见 §7.1）；
- R1 自身耐压 ≥ 150 V、功耗 15 mW，是**第二重**"限流 + 分压"。

## 5. 注入电流计算（全部用戴维南等效）

### 5.1 相通道 / VN 通道的戴维南等效

```
源侧：V_s = V_ph × k          （k = 10k/(220k+10k) = 0.0434783）
      R_th(node) = R1 ∥ R2 = 220k ∥ 10k = 9.5652 kΩ
      R_th(ADC)  = R1 ∥ R2 + Rs = 9.5652k + 10k = 19.565 kΩ
```

> **审核指出的"漏戴维南"就在这里**：从 ADC 引脚往回看，源阻抗是 **19.565 kΩ**，不是 1 kΩ。
> 且当节点电压高于引脚钳位点时，注入电流由 `(V_s − V_clamp) / R_th(ADC)` 决定；
> 用 `V_s / Rs` 会高估 2.0 倍以上（`19.565/10 = 1.96`）。

### 5.2 正注入（TT_a 要求 = 0 mA，故判据是"节点不得越过 3.3 V"）

## 6. 掉电反灌（控制板 3.3 V 掉、底板仍带电）

### 6.1 电流路径的统一模型

掉电时 `V_rail` 从 3.3 V 衰减到 ~0 V（LDO 输出电容 + MCU 静态电流 + 本板负载）。
所有跨板输入都会经 **"本板串联电阻 → 引脚 → MCU 内部 ESD 上二极管 → 3.3 V 轨"** 灌入。
统一公式：

```
I = (V_src − V_rail − V_F) / R_total        V_F ≈ 0.55 V（小电流下硅 ESD 上管）
```

### 6.2 逐路径反灌电流（取 `V_rail = 0.6 V`、`V_F = 0.55 V`，即轨已跌到接近 0 的最不利时刻）

| 路径 | `V_src`（底板最坏） | `R_total` | 反灌电流 @0.6 V | 说明 |
|---|---:|---:|---:|---|
| **SHA/SHB/SHC** | 60 V | 230 kΩ（R1+Rs） | **0 µA** | 节点 = 2.609 V，**低于 ESD 门槛 3.9 V ⇒ 二极管根本不导通** |
| IOUTA/B/C | 3.05 V | 1 kΩ | **1.90 mA** ×3 = **5.70 mA** | 主导项 |
| CBUS | 2.0 V | 1 kΩ | **850 µA** | |
| NTC | 2.5 V | 10 k + 4.7 k | **287 µA** | 与 NTC 阻值有关（此处按 10 kΩ@25 ℃） |
| VBUS | 1.46 V | 5.53 k + 4.7 k | **30 µA** | |
| FAULT | 0 V（低有效） | 10 kΩ + 4.7 k | **0 µA** | 无故障时 `V_src = 3.3 V` ⇒ `3.3 − V_rail − 0.55 < 0` ⇒ **仍为 0**（不会把底板 3.3 V 反灌进本板） |
| 串口 RX/TX（外部 5 V 误接） | 5 V | 1 kΩ | **3.85 mA** ×2 = 7.70 mA | 仅在"5 V 适配器 + 掉电"同时发生 |

> 完整分析必须解**自洽方程** `I_backfeed(V_rail) = I_absorbed(V_rail)`，见 §6.4。

### 6.3 相通道的"零反灌"是分压比带来的性质（不是靠器件）

```
节点反灌起始条件： V_ph × (1/23) ≥ VDD + 0.6 V   （掉电时 VDD ≈ 0）
⇒ V_ph ≥ 0.6 × 23 = 13.8 V （轨完全为 0 V 时）
⇒ V_ph ≥ 3.9 × 23 = 89.7 V （轨被抬到 3.3 V 时）
```

⇒ **只要相端 ≤ 89.7 V，相通道在任何掉电状态下都 0 反灌。** 60 V 设计点有 1.5× 余量。

### 6.4 3.3 V 轨的保护：为什么"泄放电阻"不成立、"齐纳钳位"成立

反灌电流必须被"吃掉"，否则轨会浮起来。这一节把"轨压"当未知量解**自洽方程**：

```
反灌电流  I_bf(V_rail) = Σ max(0, V_src,i − V_rail − 0.55) / R_i     （§6.2 的 8 条路径）
吸收电流  I_ab(V_rail) = V_rail / R_bleed                            （若装泄放电阻）
                        或 = 0                                        （若什么都不装）
稳态轨压 = 使 I_bf(V_rail) = I_ab(V_rail) 的 V_rail
```

| 方案 | 稳态轨压 | 常态损耗 | 判定 |
|---|---:|---:|---|
| ① **什么都不装** | **3.00 V**（`I_bf` 在 3.0 V 处自然归零） | 0 | ✅ 轨压安全（< 3.6 V），但**无兜底**：若 LDO 反向路径（措施 2）把电流带走则更低，若某条路径电压更高则随之抬升 |
| ② **1 kΩ 泄放**（原文 §2.4 方案 a） | **2.97 V** | **3.30 mA（占 55 mA 预算 6 %）** | ⚠️ 效果与"什么都不装"几乎一样（3.00 → 2.97 V），**却常态多耗 3.3 mA**。**不划算** |
| ③ **220 Ω 泄放** | 3.00 V | **15 mA** | ❌ 常态耗 27 % 预算，收益仍≈0 |
| ④ **3.6 V 齐纳 `D_Z1`**（本设计） | **3.60 V（钳位）** | **0**（3.3 V < `V_Z,min` 3.4 V，漏电仅 µA 级） | ✅ **最佳** |
| ⑤ **齐纳（最坏：5 V 误接也发生）** | 3.60 V | `I_Z = 2×(5−3.6−0.55)/1k = **1.70 mA**`，`P_Z = 3.6 V × 1.70 mA = **6.1 mW**` | ✅ 对 225–300 mW 余量 **37×** |

**齐纳方案的关键定量结论**：齐纳把轨钳在 **3.6 V** 后，**底板侧的 6 条通道全部自动截止**
（`3.3 − 3.6 − 0.55 < 0`），只剩外部 5 V 误接的 2 条通道各灌 850 µA ⇒ **总注入仅 1.70 mA**。
这比"轨停在 0.6 V"时的 14.57 mA **小 8.6 倍**——**钳位不只是保护轨，还反过来把注入电流压小了**。

> **为什么原文的"1 kΩ 泄放"推理不成立**：它的隐含假设是"反灌电流会被泄放电阻全部吸走"，
> 但泄放电阻的电流是 `V_rail/R`，**正比于轨压**；而反灌电流在轨压升高时**下降**——
> 两者在 3.0 V 附近就自然平衡了，**与泄放电阻取值几乎无关**（②③ 两行验证了这一点）。
> 正确的做法是把轨**钳位**（齐纳/TVS），不是"泄放"。**据此撤销 `03` §2.4 的方案 (a)。**

> **为什么不干脆什么都不装（方案 ①）**：自洽解 3.00 V 依赖 `V_src` 的典型值（IOUT 3.05 V、CBUS 2.0 V）。

## 7. 高压侧钳位：TVS 与判据

### 7.1 相线入口 TVS（`D1`–`D3` = SMBJ33A）

| 项 | 数值 | 依据 |
|---|---|---|
| 反向工作电压 `V_RWM` | **33 V** | 手册 |
| 击穿电压 `V_BR` | **36.7 – 40.6 V** @1 mA | 手册 |
| 最大钳位 `V_CL` | **53.3 V** @`I_PP = 11.3 A`（10/1000 µs） | 手册；与本仓库 V3.0/V3.1 计算书口径一致（`SMBJ33A，Vwm 33 V / Vclamp 53.3 V`） |
| 峰值脉冲功率 | 600 W（10/1000 µs） | 手册 |
| **与分压比的关系** | `53.3 V × 1/23 = 2.32 V`（节点） < 3.3 V ✅ | 本文件计算 |
| **TVS 动作时 R1 的电流** | `(60 − 53.3)/220 k = 30 µA`（60 V 感性尖峰）；浪涌时 `(1000 − 53.3)/220 k = **4.31 mA**` | 本文件计算 |
| 动作时 R1 瞬时功率 | 8/20 µs 浪涌下 `(1000−53.3)²/220k = 4.08 W`（峰值） | 需 R1 为 0805（脉冲耐量足够），0603 不可 |
| 常态漏电 | SMBJ33A `I_R ≤ 1 µA @ V_RWM = 33 V`；本项目相端 ≤ 16.8 V 常态 ⇒ 漏电 ≪ 1 µA | 手册 |
| **与 40 V 母线的关系** | 40 V 母线相端峰值可达 40 V > `V_RWM` 33 V ⇒ **TVS 在 40 V 母线上会轻微导通**。本项目母线 **12.0–16.8 V**，相端峰值 ≤ 16.8 V ⇒ **完全不导通**。若将来跑满 40 V 母线，须换 **SMBJ36A（V_RWM 36 V）** 并把 §5.2 的 76 V 设计点复核 | ⚠️ 已在 §9 列出 |

> **TVS 的作用定位（不夸大）**：它**不是**用来"保护 MCU 引脚"的（引脚由分压比保护），
> 而是用来 (1) 挡 `J5` 三相取样连接器引入的 ESD/EOS，(2) 挡感性回馈与浪涌，
> (3) 保护 R1 的耐压（若无 TVS，R1 要独扛全部浪涌电压）。
> **SMBJ33A 的单向特性在负向是正偏导通**（≈ −0.7 V），顺带把相端负下冲钳在 −1 V 附近——
> 这是**免费**的负压保护，不需要额外器件。

### 7.2 "只加对地肖特基会在 −0.3 V 就导通，要不要？"——判据

**判据（三步）**：

```
第 1 步：算出内部 ESD 下二极管的最大注入电流
        I_inj,neg = (V_ph,min × k + V_F,ESD) / R_th(ADC)
        V_ph,min = 实测/规格给定的相端最负下冲
第 2 步：与 Table 15 / Table 52 的 −5 mA 比
第 3 步：只有当 I_inj,neg 接近 −5 mA（例如 > 1 mA）才装对地钳位
```

本项目代入：`V_ph,min = −20 V` ⇒ `I_inj,neg = 8.7 µA`，**是限值的 1/575** ⇒ **不装**。
装了对地肖特基后，其反向漏电还会经 `R_th(node) = 9.565 kΩ` 产生 `0.2–0.3 mV` 直流偏置，
并给三相引入**不一致**的漏电失配。**净收益为负。**

⇒ **结论：相通道不装对地肖特基。** 保留 `D1–D3` 的"可选负压钳位"焊盘仅作为实测超标后的补救位
（判据：实测相端下冲 < −35 V，或实测 `I_inj,neg` > 1 mA）。

### 7.3 相通道"装/不装钳位"的最终判据表

| 情形 | 本次设计处置 | 触发补装的条件 |
|---|---|---|
| 正过压（60 V 尖峰） | **分压比 1/23 自行消化**，节点 2.609 V | 若实测相端 > 76 V 常态出现 |
| 正浪涌/ESD | **SMBJ33A**（相线入口，每相 1 只） | 默认装 |

| 掉电反灌 | **分压比 > 89.7 V 才起始**，无需器件 | 无 |
| 3.3 V 轨被抬 | **`D_Z1` 齐纳 3.6 V**（默认装） | 原文的"1 kΩ 泄放"**撤销**（§6.4 证明其无效且额外耗 3.3 mA） |

## 10. 关键计算式汇总（便于复核）

```
相分压比        k      = R2/(R1+R2) = 10k/(220k+10k) = 0.0434783 = 1/23.00
节点电压        V_node = V_ph × k
ADC 端电压      V_adc  = V_node × R2/(R2+Rs)
节点源阻抗      R_th   = R1∥R2 = 9.5652 kΩ
ADC 端源阻抗    R_th'  = R1∥R2 + Rs = 19.565 kΩ          ← 审核要求的戴维南
注入电流        I_inj  = (V_ph×k − V_clamp) / R_th'       （正）
                I_inj  = (V_ph×k + V_F,ESD) / R_th'       （负）
理论限流上界    |I_inj| ≤ V_ph / (R1 + Rs) = V_ph / 230 kΩ = 4.348 µA/V
反灌电流        I_bf   = (V_src − V_rail − V_F) / R_total
VN 星形         V_star = V_avg × R_load/(R_star + R_load)，R_load = R1 + R2∥Rs = 225 kΩ
                R_star = R_VN/3 = 3.333 kΩ（R_VN = 10 kΩ×3）
RC 常数         τ = R_th' × C = 19.565 kΩ × 150 pF = 2.935 µs，fc = 54.2 kHz
建立            t_s = 640.5 / 42.5 MHz = 15.07 µs = 5.14 τ
跟踪误差        ΔV ≈ (dV/dt) × τ
```

**`ADCCLK = 42.5 MHz` 的合法生成路径**（两条，任选，均取自原文）：

| 路径 | 配置 | 出处 |
|---|---|---|
| A（**推荐**） | `RCC_CFGR.ADC12SEL = 01`（**PLL "P" clock** 选作 ADC1/2 clock），`ADC12_CCR.PRESC = 0001`（÷2） | `ADC12SEL` 位域原文见 **RM0440 §7.4.12 / p.323**；`PRESC[3:0]` 原文见 **RM0440 §21.8.2 p.707** |
| B（备选） | `ADC12SEL = 10`（**System clock**），`ADC12_CCR.CKMODE = 11`（`adc_hclk/4`） | `CKMODE[1:0]` 原文见 **RM0440 §21.8.2 p.707** |

> ⚠️ **前置条件未闭合（列入 §7 U-6）**：路径 A 要求 `ADC12SEL` 的输入源 = **PLLP**，
> 而按 `03` §7 现有时钟树 `PLLR = 2` ⇒ PLLP 也是 **170 MHz**（若 PLLP 被配置成 85 MHz 则不成立）。
> 170 MHz 经 CCR 的 `PRESC` 可得到 170/1、/2=85、/4=42.5 —— **`PRESC` 原文档位里没有 ÷4**（只有 1,2,4,6,8,10,12,16,32,64,128,256），
> 但 **`CKMODE = 11`（`adc_hclk/4`）就是 ÷4** ⇒ **路径 B 用 170 MHz / 4 = 42.5 MHz 一定成立**（需 system clock 为 50 % 占空比，RM0440 p.707 原文要求）。
> ⇒ **固件定稿时按路径 B 配置，`ADCCLK` 必为 42.5 MHz**；路径 A 需先确认 PLLP 的实配值。

### 1.3 ★ 双 ADC 同步模式：配置方式、触发源、同时性依据、DMA

#### (a) 选哪个模式？——**双重规则同步（Regular simultaneous mode only）**

| 候选 | `ADCx_CCR.DUAL[4:0]` | 触发组 | 采样是否与主 ADC 同时开始 | 本项目 |
|---|---|---|---|---|
| **Regular simultaneous mode only** | **`00110`** | **规则组**（`EXTSEL`） | **是**（原文：*"A simultaneous trigger is provided to the slave ADC"*） | ✅ **采用** |
| Injected simultaneous mode only | `00101` | 注入组（`JEXTSEL`） | 是 | ❌ 注入组只有 4 个寄存器、且与规则组抢占关系复杂，本项目无抢占需求 |
| Combined regular + injected simultaneous | `00001` | 两者 | 是 | ❌ 无注入需求 |
| Interleaved mode only | `00111` | 规则组 | **否**（从 ADC **延迟** 若干周期启动，`DELAY[3:0]`） | ❌ **交错模式明确不是同时采样** |
| Alternate trigger mode only | `01001` | 注入组 | **否**（交替） | ❌ |

**原文（`DUAL[4:0]` 位域，RM0440 §21.8.2 p.708，逐字）**：
> `00000`: Independent mode
> `00001`: Combined regular simultaneous + injected simultaneous mode
> `00010`: Combined regular simultaneous + alternate trigger mode
> `00011`: Combined Interleaved mode + injected simultaneous mode
> `00100`: Reserved
> `00101`: Injected simultaneous mode only
> **`00110`: Regular simultaneous mode only**
> `00111`: Interleaved mode only
> `01001`: Alternate trigger mode only

#### (b) ★ 同步模式下「从 ADC 的采样真的与主 ADC 同时开始」——原文依据

| # | 原文（逐字摘录） | 出处 |
|---:|---|---|
| 1 | *"**A simultaneous trigger is provided to the slave ADC.**"* —— 紧接在 *"The external trigger source comes from the regular group multiplexer of the **master** ADC (selected by the `EXTSEL` bits in the `ADC_CFGR` register)."* 之后 | **RM0440 §21.4.30「Regular simultaneous mode with independent injected」p.661**（**这是本项目同步性的第一手依据**） |
| 2 | *"In dual ADC mode the start of conversion is **triggered alternately or simultaneously by the ADCx master to the ADC slave**, depending on the `ADCx_CCR` register."* | **RM0440 §21.4.30「Dual ADC modes」p.657** |
| 3 | *"**ADC1 and ADC2 are tightly coupled and can operate in dual mode (ADC1 is master).**"* | **RM0440 §21.4.4 / ADC 实现表附近 p.593**（原文句） |
| 4 | *"Each ADC master **shares the same input triggers with its ADC slave** as described in Figure 97."*（Figure 97 标题：*Triggers sharing between ADC master and ADC slave*） | **RM0440 §21.4.18 p.617** |
| 5 | *"In regular simultaneous or interleaved modes: once the user sets bit `ADSTART` or bit `ADSTP` of the master ADC, the corresponding bit of the slave ADC is **also automatically set**."* | **RM0440 p.658** |
| 6 | *"In regular simultaneous mode, ... the external trigger source comes from the regular group multiplexer of the master ADC ... A simultaneous trigger is provided to the slave ADC."* 配图 **Figure 139「Regular simultaneous mode on 16 channels: dual ADC mode」**：主/从两路的 *Sampling* 段在同一个 Trigger 下**上下对齐、同时开始**，*End of regular sequence* 也在同一时刻 | **RM0440 p.661–662** |
| 7 | 约束①：*"Do not convert the **same channel** on the two ADCs (no overlapping sampling times for the two ADCs when converting the same channel)."* → 本项目浮空相（ADC1）与 VN（ADC2）是**不同通道**（`IN1/2/3` vs `IN9`），**满足** | **RM0440 p.661**（同注也见 p.660） |
| 8 | 约束②：*"one must convert sequences with the **same length** or ensure that the interval between triggers is longer than the longer conversion time of the 2 sequences."* → 本项目**两侧序列长度都取 2**（§3.3），**满足** | **RM0440 p.661** |

> **结论（有原文、无"误差可忽略"式论证）**：把 `ADC12_CCR.DUAL = 00110`（规则同步），
> 主 = **ADC1**，从 = **ADC2**，两者由**同一个** `TIM1_TRGO2` 触发；
> 从 ADC 收到的是**硬件产生的同步触发**，两侧 `Sampling` 相位在同一个触发沿开始。
> 因此**浮空相（ADC1）与 VN（ADC2）是同一时刻进入采样保持的**——这是硬件同步特性，不是靠事后误差估计。
> **注意**：两侧的**采样窗长度可以不同**（本项目 ADC1 侧 640.5 档、ADC2 侧电流通道 92.5 档），
> 但**采样起点相同**；「同时」指的是**采样开始时刻**，这一点必须写清楚（§7 U-1 要求实测复核）。

| 循环/单次模式由 `CCR.DMACFG` 定，**主从 `ADC_CFGR.DMACFG` 不再相关** | *"bit `DMACFG` of the `ADCx_CCR` register must also be configured ... (bits `DMACFG` of master and slave `ADC_CFGR` are **not relevant**)"* | **RM0440 p.671** |
| `MDMA` 位只能在 `ADSTART = 0` 时写 | *"allowed to write these bits only when `ADSTART = 0`"* | **RM0440 §21.8.2 p.708** |
| 两侧 EOC 都置位才发一次 DMA 请求；读 `CDR` 会**同时清两个 EOC** | *"A single DMA request is generated each time both master and slave EOC events have occurred ... Both EOC flags are cleared when the DMA reads the `ADCx_CDR` register."* | **RM0440 p.671 / p.661** |
| ⚠️ 若主从序列**长度不同**，多出来的那些转换**不产生 DMA 请求** | *"conversions in the master's sequence as in the slave's sequence. Otherwise, the remaining conversions does not generate a DMA request."* | **RM0440 p.661** |
| 数据寄存器宽度 / 对齐 | `ADC_DR` 为 **16 bit**；`ALIGN = 0` = 右对齐（本项目），`ALIGN = 1` = 左对齐；左对齐在半字边界对齐（6 bit 除外） | **RM0440 §21.4.26 p.636** + `ALIGN` 位域 **§21.7.x p.686** |
| `ADCx_CDR` 位域 | `[31:16]` = **Regular data of the slave ADC**；`[15:0]` = **Regular data of the master ADC** | **RM0440 §21.8.3 p.710** |
| 寄存器地址映射 | `0x000–0x0FC` 主 ADC；`0x100–0x1FC` 从 ADC；`0x300–0x30C` 主从公共 | **RM0440 Table 180「ADC global register map」p.710** |

> **⇒ 本项目 DMA 配置结论**：`MDMA = 10`、`DMACFG = 1`（循环模式，`ADSTART` 期间持续搬运）、
> **1 个 DMA 通道**读 `ADC12_CDR`，每个触发得到 **1 个 32 bit 字**：
> `[15:0]` = ADC1（浮空相），`[31:16]` = ADC2（VN 或电流）→ **天然成对，不存在配对错位的可能**（比两通道方案少一个同步风险点）。
> `ALIGN = 0`（右对齐），12 bit 有效位在低 12 位。

## 2. 采样时间的选择（两个独立过程，六条支路分别算）

### 2.1 两个过程的定义

| 过程 | 物理含义 | 判据 |
|---|---|---|
| **过程 A：外部 RC 阶跃恢复** | 换相（或 PWM 边沿）使被测节点发生阶跃后，**外部 RC 网络恢复到目标精度所需的时间**。它是"**什么时候才能开始采样**"的约束 | `t_ready = 9.03 · τ_ext`，`τ_ext = R_th_ext × C_ext` |
| **过程 B：ADC 采样保持建立** | 采样开关闭合后，**采样电容在采样窗内充到目标精度**。它是"**采样窗要多长**"的约束 | `t_S ≥ 9.03 · τ_adc`，`τ_adc = R_src × (C_ext + C_sh)`，`C_sh = 5 pF`（DS12589 Table 60 p.119 原文） |

**为什么是 9.03 τ**：单极点网络从"整程阶跃"恢复到 **0.5 LSB**（12 bit ⇒ `3.3/4096/2 = 0.403 mV`）所需的半程数为
`τ·ln(2×4096) = τ·ln 8192 = 9.010 τ`；取手册常引的 **9.03 τ**（等价于 0.05 % 建立）即 **13.53 µs** 量级。
作为对照，若用 0.1 % 判据则是 `8.32 τ`。**本文件全程用 9.03 τ（更严）**，两套都给出（§2.3 末列）。

### 2.5 ★ 孔径落位：`03` 与 R3 都漏掉的一条硬约束

过程 A、B 只管"**采多久**"和"**何时可以采**"，但**相/VN 支路还有第三条约束**：
**相端节点只在「低边导通窗口」内才等于低轨**，其余时间被高边拉到母线上。
⇒ **整整 15.071 µs 的孔径必须**（a）**整体落在低边导通窗口 `W_ls` 之内**，（b）**孔径起点 ≥ 9.03 τ_ext**。

**低边导通窗口**（中心对齐互补 PWM，低边窗口以计数谷为中心）：

```
W_ls = 2 · min(D, 1−D) · T_pwm − t_dead
```

| `f_pwm` | `T_pwm` | `D = 5 %` | `D = 20 %` | `D = 50 %` | `D = 80 %` | `D = 90 %` | `D = 95 %` |
|---|---:|---:|---:|---:|---:|---:|---:|

> 代价是**过程 B 过不了 247.5 档（需 13.53 µs > 5.82 µs）** —— 见 §3.5 给出的三条出路。

### 2.6 时间常数匹配（同步采样的前提）

同步采样只解决"**同一时刻**"，不解决"**两条链路相位一致**"。
若相通道与 VN 通道的 `τ` 不同，同一时刻采到的两个值对应的**物理时刻**仍不同。

| 支路 | `R_th_ext` | `C` | `τ` | 相对相通道的偏差 |
|---|---:|---:|---:|---:|
| 相分压（基准） | 14.265 kΩ | 100 pF | **1.4270 µs** | — |
| VN（`R_VN = 10 kΩ×3`） | 14.271 kΩ | 100 pF | **1.4276 µs** | **+0.042 %** |
| 730 Hz 处两路相位差 | `arctan` 差值 | — | — | **< 0.001°** |

⇒ **必须**（写入硬性规则）：**三路相分压与 VN 的 `C` 同为 100 pF C0G 且同一批**（`03` 规则 R2 保留），
`R_VN = 10 kΩ×3` 与相分压共用 `220k / 10k / 4.7k` 料号（`03` §3.5 保留）。

## 3. 一个 PWM 周期内的双 ADC 同步调度

### 3.1 三个前提

| # | 前提 | 依据 |
|---:|---|---|
| 1 | 浮空相（ADC1）与 VN（ADC2）**必须同一时刻**采样 | 用户拍板 + §1.3(b) 原文 |
| 2 | 两者**只能各占一个采样保持器**，ADC1 与 ADC2 各只有一个 | 任务给定；RM0440 Figure 82 p.594 单 ADC 框图（单 S/H） |
| 3 | **电流（相电流 / CBUS）只能在低边导通窗口内采**（低边分流），**相/VN 也只在低边窗口内等于可判读的低轨电压** | 六步换相 + 低边分流拓扑 |

### 3.2 触发点在哪

**触发源**：`TIM1_TRGO2` = `OC4REF` 上升沿（`TIM1_CR2.MMS2` 选 `OC4REF`）→ `ADC1/2 EXTSEL = 01010`。

**触发位置（固件每周期算一次，写 `TIM1_CCR4`）**：

```
设低边导通窗口中心 = 计数谷（中心对齐模式）
设孔径起点须 ≥ 9.03 τ_ext = 12.88 µs（自低边导通窗口起点算起）
设孔径长度 A = 15.071 µs（640.5 档）
⇒ 孔径起点 t0 = 12.88 µs（贴着下界，使读数误差最小）
⇒ 孔径中心   tc = t0 + A/2 = 20.42 µs
⇒ CCR4 = (W_ls/2) − tc + t_LATR        （以计数谷为 0 点、向上计数为正）
   例：D = 50 % ⇒ W_ls = 49.7 µs ⇒ CCR4 = 24.85 − 20.42 + 0.06 = 4.49 µs（≈ 190 个 TIM1 计数 @42.5 MHz 等效）
```

> `t_LATR ≤ 2.5 / f_ADC = 58.8 ns`（DS12589 Table 60 p.119，`CKMODE = 00`）⇒ **+0.06 µs 固定补偿**。
> ⚠️ **`CCR4` 的最优点必须实测确认**（列入 §7 U-3）：上式的 `t0 = 9.03 τ_ext` 是"理论最小起点"，
> 实际最优起点受 `R1/R2/Rs/C` 容差、PCB 寄生电容、低边 MOSFET 开关时间影响，**需示波器配合标定**。

### 3.3 通道配对（谁能同触发、谁必须串联）

| 轮次 | ADC1（主） | ADC2（从） | 触发 | 同步？ | `t_CONV` |
|---|---|---|---|---|---|
| **R1** | **浮空相**（`PA0`/`PA1`/`PA2` 按扇区选一，640.5 档） | **VN**（`PC3`，640.5 档） | `TIM1_TRGO2` #1 | ✅ **同刻采样** | **15.365 µs** |
| **R2** | **IOUTB**（`PB0`，92.5 档） | **该扇区的一路相电流**（`PC4` 或 `PC5`，92.5 档） | `TIM1_TRGO2` #1（**同一次触发内的第 2 个转换**） | ✅ 同刻采样（两侧序列长度同为 2） | **2.471 µs** |
| **R3** | （空闲 / 可选第二路相电流） | **CBUS**（`PA7`，92.5 档）+ 可选另一路相电流 | 独立触发或 `TRGO` | 不要求同步 | **2.471 µs** |
| **R4** | （空闲） | **VBUS**（`PC1`，247.5 档）+ **NTC**（`PA4`，247.5 档） | 独立触发 | 不要求同步 | **6.118 × 2 = 12.24 µs** |

**逐个说清**：

| 通道 | 放在哪 | 为什么 |
|---|---|---|
| 浮空相（`PA0/PA1/PA2`） | **ADC1，R1** | `PA2` 原文**只有 `ADC1_IN3`**（§0.1 注 2）⇒ 浮空相**必须**由 ADC1 采，无选择余地 |
| VN（`PC3`） | **ADC2，R1** | 用户拍板的新位置；`ADC12_IN9` 有 ADC2 侧 |
| IOUTB（`PB0`） | **ADC1，R2** | `PB0` 原文**只有 `ADC1_IN15`**（无 ADC2 侧）⇒ 必须由 ADC1 采 |
| 该扇区的一路相电流 | **ADC2，R2** | 与 IOUTB **同触发同步**，两者都是 92.5 档，序列长度对齐，**天然成对** |
| CBUS | **ADC2，R3** | 母线电流只在低边导通期有值；**必须**排在低边窗口内。**不要求与谁同步**，单独一轮最省事 |
| 第二路相电流 | **ADC2，R3（可选）** | 六步换相下同一时刻只有一相低边在斩波 ⇒ **一路相电流 + CBUS 即覆盖该扇区**；第二路只在诊断/扇区切换时补采 |
| **VBUS** | **ADC2，R4** | 慢变量（`RC = 2.54 kΩ × 100 pF`）；`03` §4.2 的分辨率算例已成立。**与同步无关，可任意轮次** |
| **NTC** | **ADC2，R4** | 同上；`247.5` 档（需 3.00 µs） |

> **为什么 R2 必须与 R1 分轮**：ADC1 与 ADC2 **各只有一个采样保持器**，
> 同一时刻每侧只能采一路 ⇒ `浮空相+VN` 与 `IOUTB+相电流` **必然串联**，无法压进同一对孔径。
> **R1 与 R2 之间不需要第二个触发沿**：`DUAL = 00110` 的同步模式下，一次触发会让主从**各自走完 2 步序列**，
> 第 2 步在同一触发系统内同步推进（RM0440 p.661 的「same length」约束已满足）。

### 3.5 ★ 结论：放不放得进？必须提高 PWM 频率到多少？

**(a) 先看"总时长"**：`20 kHz`、`25 kHz` 下**全量放得进一个周期**；`≥ 30 kHz` 放不进（先砍 VBUS/NTC）。

**(b) 真正的瓶颈不是总时长，而是"低边导通窗口"**（§2.5）：

| 约束 | 需求 | @20 kHz 容许的占空比 | 判决 |
|---|---|---|---|
| R1（浮空相 + VN，640.5 档） | `W_ls ≥ 27.95 µs` | **`D ∈ [28 %, 72 %]`** | ★ **这是本设计最紧的一条** |
| R2（IOUTB + 相电流，92.5 档） | `W_ls ≥ 5.24 µs` | `D ∈ [5.5 %, 94.5 %]` | ✅ 宽松 |
| R3（CBUS + 相电流，92.5 档） | `W_ls ≥ 5.24 µs` | `D ∈ [5.5 %, 94.5 %]` | ✅ 宽松 |
| R4（VBUS + NTC） | 无窗口约束 | 任意 | ✅ |

**(c) 明确结论（三条，按优先级）**：

| # | 结论 | 代价 / 适用 |
|---:|---|---|
| **① 保持 20 kHz** | **可以跑，但固件必须限制 `D ∈ [28 %, 72 %]`**（等效调制比上限 ≈ 0.72）。对六步换相**首版调试够用**（`03` §5.2 已写明固件要限最小/最大占空比） | 零硬件改动；**高油门受限** |
| **② 保持 20 kHz 且放开占空比** ⇒ **把 VN 的采样档从 640.5 降到 247.5** | 依据：VN 支路 `R_src = 14.271 kΩ` 与相通道实质相同，降档后过程 B 需求 13.53 µs > 5.824 µs ⇒ **过程 B 过不了** ⇒ **必须把 `R_VN` 从 `10 kΩ×3` 降到 `1 kΩ×3`**（星点 `R_s` 333 Ω ⇒ `R_th = 4.7k + [220.333k∥10k] = 14.19 kΩ`，**几乎没改善**）⇒ **此路不通** | ❌ **否决**（VN 支路的时间常数由 `220k/10k` 主导，调 `R_VN` 无效） |
| **③ 缩短相/VN 的 `C_ext`** ⇒ **100 pF → 47 pF** | `τ_ext = 0.670 µs` ⇒ `9.03 τ = 6.05 µs` ⇒ **`W_min = 21.12 µs`** ⇒ **@20 kHz `D ∈ [21 %, 79 %]`**；@25 kHz `D ∈ [27 %, 73 %]`；@30 kHz `D ∈ [32 %, 68 %]`。过程 B 需求降到 **6.70 µs** ⇒ **可用 247.5 档（5.824 µs？仍差 0.88 µs）——不够，须用 640.5 档**；孔径内残差反而降到 **0.111 LSB** | 需要改 `03` §2.5 / `04` BOM 的 3+1 只电容（`C20–C22`、`C23`）与 R3 文档 §8 的 `150 pF` 建议一起定稿；**代价是 PWM 纹波抑制变差（20 kHz 处衰减量减少约 6 dB）** |

**(d) 若要求"更高 PWM 频率"**：

| 目标 | 必须同时满足 | 判决 |
|---|---|---|
| 25 kHz | `W_ls ≥ 27.95 µs` ⇒ `D ∈ [35 %, 65 %]`；全量 35.67 µs < 40 µs ✅ | ⚠️ **可跑，但占空比窗口只剩 30 %** |
| 30 kHz | `W_ls ≥ 27.95 µs` ⇒ `D ∈ [42 %, 58 %]`；全量 35.67 µs > 33.3 µs ❌ | ❌ **不可行**（除非"减少通道"：砍掉 VBUS/NTC 到 6 周期一次，且 `D` 只剩 16 %） |
| 40 kHz | 同上，`D ∈ [52 %, 48 %]` **无解** | ❌ **不可行** |

> **⇒ 明确结论（用户要求的"如果放不进就给出具体数字"）**：
> **不需要提高 PWM 频率**。20 kHz 是**当前 `C_ext = 100 pF` 取值下能同时满足三条约束的最高整数频率**；
> 提高频率的收益（更小电流纹波）**小于**代价（占空比窗口急剧收窄）。
> **若将来确需 25 kHz 以上，必须先把相/VN 的 `C_ext` 从 100 pF 降到 47 pF**（结论 ③），
> 此时 30 kHz 下仍有 `D ∈ [32 %, 68 %]`。

### 4.1 扇区与理想过零位置

六步换相：换相频率 = `6 × f_elec`，**扇区长度** `= 1/(6 f_elec)`；理想过零（BEMF 过 0）在**换相后 30° 电角度 = 扇区中点**。

| 口径 | `f_elec` | 扇区长度 | 理想过零位置（扇区中点） | 换相周期 |
|---|---:|---:|---:|---:|
| **`p = 2`（4S 电机的一种可能极对数）** | **487 Hz** | **342.2 µs** | **171.1 µs** | 5.85 kHz |
| **`p = 3`** | **730 Hz** | **228.3 µs** | **114.2 µs** | 4.38 kHz |
| （更高）`p = 3` 备选 | 1000 Hz | 166.7 µs | 83.3 µs | 6.0 kHz |

### 4.2 消隐预算与占比

| 项 | 取值 | 依据 |
|---|---|---|
| 消隐起点 | **换相沿（`t = 0`）** | 换相瞬间相端发生台阶跳变，RC 必须恢复 |
| 消隐下界（过程 A） | **≥ 9.03 τ_ext = 12.88 µs**（相/VN 支路，§2.3） | 本文件 §2.3 |
| 消隐上界 | **≤ 扇区的 15 %**（比例口径，取代初版的"3 个 PWM 周期"） | R4 审核意见第 2 条 |

| 口径 | 扇区 | **消隐 = 15 % 扇区** | 消隐 = 3 个 PWM 周期 @20 kHz | 对比 |

### 4.3 ★ 论证：消隐窗口不会吃掉扇区中点的过零

| 口径 | 扇区 | 消隐终点 | **理想过零（扇区中点）** | **过零落在消隐之外多少** | 相对中点占比 |

**多余量检查（更严格的一条）**：BEMF 在换相后 30° 电角度处过零，**理想情况下过零只可能落在扇区中点**；
但存在换相角误差与相移，实际过零会在中点附近展宽。取一个宽松的窗口 `±20°` 电角度（扇区的 `±33 %`）：

| 口径 | `±20°` 对应的扇区范围 | 最早可能的过零 | 消隐终点 | 是否被屏蔽 |

**初版"≥ 3 个 PWM 周期"（730 Hz 时 150 µs = 扇区 65.7 %）确实会屏蔽掉扇区中点的过零**，该写法**已废弃**。

### 5.3 过零判定的数据从哪来

| 项 | 做法 |
|---|---|
| **数据源** | **同一次 `TIM1_TRGO2` 触发下的同一个 `ADC12_CDR` 32 bit 字**：`[15:0]` = ADC1 采的**浮空相**，`[31:16]` = ADC2 采的 **VN**（§1.3(d) 原文对齐方式） |
| **判据** | 比较 `V_float` 与 `k_gain × V_N` 的**符号差**是否变号 |
| **增益归一系数** | `k_gain = 23.33/23 ≈ 1.0145`（`03` §3.2，`R_VN = 10 kΩ×3` 使 VN 支路直流增益为 `1/23.33`）。**可标定**（上电自检） |
| **配对保证** | `MDMA = 10` 的**单 DMA 请求 + 单个 32 bit 字**天然把两侧数据封在一起 ⇒ **不存在"取到上一轮的 VN 配这一轮的浮空相"的配对错位** |
| **消隐期处理** | 消隐窗口内**不做过零判定**（但 ADC 照常采样）。实现上：换相后由固件丢弃 `t < 消隐` 的轮次 |
| **符号判定而非幅值** | 过零判据只看**符号变化**，所以 §2.6 的 0.042 % 时间常数失配、§2.5 的 0.236 LSB 孔径残差都**直接进入定时误差预算**（不做"可忽略"处理，见 §6） |

## 9. 计算式汇总（便于复核）

```
采样档（真实 8 档）   SMPR = {2.5, 6.5, 12.5, 24.5, 47.5, 92.5, 247.5, 640.5} × 1/f_ADC     （RM0440 §21.4.12 p.610）
12 bit 转换时间       t_CONV = t_S + 12.5 / f_ADC                                          （RM0440 p.610）
单通道总时长          t_ch   = SMPR / f_ADC + 12.5 / f_ADC
过程 A（可采时刻）     t_ready = 9.03 × τ_ext  = 9.03 × R_th_ext × C_ext
过程 B（采样窗需求）   t_S,min = 9.03 × τ_adc  = 9.03 × R_src × (C_ext + C_sh)，C_sh = 5 pF
相分压源阻抗          R_th_ext = R_src = R1∥R2 + Rs = 220k∥10k + 4.7k = 14.265 kΩ
VN 源阻抗             R_src = Rs + [(R_VN/3 + R1) ∥ R2] = 4.7k + [223.333k ∥ 10k] = 14.271 kΩ
低边导通窗口          W_ls = 2 × min(D, 1−D) × T_pwm − t_dead
孔径落位约束          W_ls ≥ 9.03 τ_ext + A            且    t0,aperture ≥ 9.03 τ_ext
合法占空比区间        D ∈ [ (W_min + t_dead)/(2 T_pwm),  1 − (W_min + t_dead)/(2 T_pwm) ]
触发位置              CCR4 = W_ls/2 − (t0 + A/2) + t_LATR，t_LATR ≤ 2.5/f_ADC = 58.8 ns
扇区长度              T_sector = 1/(6 f_elec)
理想过零位置          换相后 30° 电角度 = T_sector / 2
消隐窗口              t_blank = min(0.15 × T_sector, …)，且 ≥ 9.03 τ_ext
扇区内整轮次数        N = floor( (T_sector − t_blank) / T_pwm )
检出分辨率            Δθ = 360° × f_elec × T_pwm / 1e6
DMA 成对数据          ADC12_CDR[15:0] = 主(ADC1)，ADC12_CDR[31:16] = 从(ADC2)
```

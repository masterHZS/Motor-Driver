## 2. ★ 它抓出的、我的真错误（已修）

### 2.1 `PA2` 没有 ADC2 通道 —— 我错了

我原先在 `tools/lib/pins.mjs` 里把 `PA0/PA1/PA2` 都记成 `ADC1/ADC2` 双通道。
**回 DS12589 Table 12 原文核对**（抽取产物 `审查/g431_table12_af.json` 的 raw 字段）：

```text
PA2：I/O TT_a - TIM2_CH3, USART2_TX, COMP2_OUT, TIM15_CH1, LPUART1_TX, UCPD1_FRSTX, EVENTOUT
     ADC1_IN3, COMP2_INM, OPAMP1_VOUT, WKUP4        ← 只有 ADC1_IN3，没有 ADC2 侧
```

**⇒ R4 的更正成立。** 后果：浮空相（`PA0/PA1/PA2` 三选一）**必须整体由 ADC1 采**；
当浮空相恰好是 C 相（`PA2`）时，它在物理上就没有 ADC2 侧可走。
好在 R4 的方案本来就是「浮空相走 ADC1」，**因此方案本身不受影响**，受影响的是我原来的表述。

### 2.2 `PC3` 的原文写法是 `ADC12_IN9`

我写的 `ADC2_IN9` 只是这台引脚 ADC2 侧的通道号；**原文是 `ADC12_IN9`**（两侧同号）。
语义上没错，但引用原文时应写 `ADC12_IN9`。已改为原文写法。

### 2.3 连带：`PF0` 我漏记了 ADC2 侧

独立复核时顺带扫出：`PF0` 原文是 `ADC1_IN10 / ADC2_IN10`（双），我原先只记了 `ADC1_IN10`。
**两处（`PA2` 多记、`PF0` 少记）都已修正**，修正后：

```text
双 ADC 通道（可同步）：PA0 PA1 PC0 PC1 PC2 PC3 PF0
仅 ADC1：PA2 PB0 PB1 PB12 PB14
仅 ADC2：PA4 PA5 PA6 PC4 PC5
```

**新增闸门**：`node tools/verify-adc-channels.mjs` —— 用 Table 12 抽取产物逐脚复核模拟通道，
与本仓库记录不一致就 `exit 1`。**这条闸门现在是我这边唯一能拦"通道记录错"的手段**
（`build.mjs check` 拦不住，因为"记错通道"是自洽的；`ref-pinmap.mjs` 也不含 ADC 信息）。

## 3. ⚠️ 我复核出的、R4 文档里的 4 处问题

### 3.1 孔径 `A` 取值少算了一个转换周期（差 0.3 µs）

R4 的 `W_min = 9.03τ_ext + A = 12.88 + 15.07 = 27.95 µs`，其中 `A` 取的是**采样窗** 15.07 µs。
但孔径应含 12 位转换的 12.5 周期：`A = 15.365 µs` ⇒ **`W_min = 28.25 µs`**。

| 口径 | `W_min` | @20 kHz 的 `D` 区间 |
|---|---:|---|
| R4 取法（只算采样窗） | 27.95 µs | [28.0 %, 72.0 %] |
| **我取法（含转换）** | **28.25 µs** | **[28.2 %, 71.8 %]** |

**是否必须含转换？取决于硬件语义**：
- 若「低边必须在采样保持开关闭合期间保持导通」⇒ 只需 15.07 µs；
- 若「低边必须在整个孔径内保持导通」⇒ 需 15.365 µs。

**取保守口径（含转换）**，因为这是余量方向。差异仅 **1.0 %**，
**不改变任何结论**（`D` 区间从 [28,72] 变 [28.2,71.8]），但报告里应写清用的是哪个口径。

### 3.2 摘要表的「快组」标签与明细表不一致（R4 自身的笔误）

R4 文档 §3.4 的列标题写 **「含电流组（R1+R2+R3）」**，但值填的是 **20.31 µs = R1+R2+R3**（正确），
而前一列写 **「快组（R1+R2）」= 17.84 µs**（正确）。**摘要表本身是自洽的。**

问题出在**闭幕词/摘要**里把它表述成「快组 R1+R2+R3 = 17.84 µs」，与明细表冲突。
按明细表：**快组 = R1+R2 = 17.835 µs**，含电流组 = **20.306 µs**，全量 = **35.67 µs**。

**我独立重算**：`15.365 + 2.471 = 17.836`（快组）、`+2.471 = 20.307`（含电流组）、
`+2.471+12.236 = 35.014`…… ⇒ 全量取决于 R4 里 R3 是否含**第二路相电流**。
按明细表 R3 含「CBUS + 可选第二路相电流」= `2.471 × 2 = 4.942`，则
`15.365 + 2.471 + 4.942 + 12.236 = 35.014 µs`，与 35.67 µs 相差 0.66 µs（R4 在 R3 里多算了一路）。

**⇒ 结论：全量在 35.0–35.7 µs 之间**（取决于 R3 排几路）。
这个区间**不影响主结论**：@20 kHz（50 µs）与 @25 kHz（40 µs）都放得进，@30 kHz（33.3 µs）都放不进。

### 3.3 扇区内「整轮次数」定义不同（11/7 轮 vs 5/3 轮）

- 我的算法：`(扇区 − 消隐) / 全量` ⇒ p=2: **11 轮**、p=3: **7 轮**
- R4 的算法：明显是按**更严的约束**算的（可能要求整轮落在**低边导通窗口**内，而非整轮落在扇区可检测段内）

**R4 的 5 轮 / 3 轮是更保守的口径** —— 若 R4 按「每个 PWM 周期只能采 1 轮、且要满足 `D` 区间」来算，
则 p=2 扇区 342 µs / 50 µs = 6.8 个周期 ⇒ 扣掉消隐期约 1 个周期 ⇒ **5 轮**，与其一致。
**⇒ 应采用 R4 的保守口径**（这是余量方向），我的 11/7 轮是上界、不是可依赖值。

# F3 · 低边源极（Q1.S / Q5.S / Q4.S）修改方案

> 对应缺陷 ③（P0，致命）。证据来自你的权威网表：
>
> | 网络 | 成员 | 含义 |
> |---|---|---|
> | `LS1_SRC` | `Q1.1, Q1.2, Q1.3`(S), **`R7.2`** | A 相低边源极**唯一的对外连接就是 R7** |
> | `LS2_SRC` | `Q5.1, Q5.2, Q5.3`(S), **`R8.2`** | B 相同理 |
> | `LS3_SRC` | `Q4.1, Q4.2, Q4.3`(S), **`R9.2`** | C 相同理 |
> | `GND` | …, **`R7.1`**, **`R8.1`**, **`R9.1`**, … | R7/R8/R9 的另一端接 GND |
>
> 即：**低边管源极 → 20 kΩ → GND，中间没有任何功率回流路径。**
> 20 kΩ 是"栅源下拉"的阻值，不可能是功率回路 —— 这是典型的"想放栅源下拉，结果把源极接地那根线漏了"。

---

## 1. 为什么这一条是致命的

三相逆变桥的电流回路是：

```
VCC_BUS → 高边管 D→S → 相线 → 电机绕组 → 另一相线 → 低边管 D→S → 功率地 → 母线电容负极
```

低边管源极**不接功率地**，这个回路就在低边管处断了：

- 低边管导通时，源极电位被 20 kΩ 抬起来（20 kΩ 上流过相电流 I 会产生 `I × 20 kΩ` 的压降）
- 哪怕只有 10 mA，压降就是 200 V —— 源极电位瞬间飞到天上，栅源电压反向击穿或完全失控
- 实际结果：**电机不会有任何转矩**，且低边管/驱动芯片大概率损坏

**结论：这根线不补，板子做出来一定不转。**

---

## 2. 原理图修改（三步）

### 第 1 步：删掉错误连接

把 `R7 / R8 / R9` 原来连到 **GND 的那一端**（网表里的 `R7.1 / R8.1 / R9.1`）连线**断开**。

> 注意：**不要删元件**。R7/R8/R9 阻值 20 kΩ 本身是对的，只是位置放错了 —— 它们是"栅源下拉电阻"，不是"源极接地电阻"。

### 第 2 步：三个低边源极短接到同一个星点

新建网络 **`LS_STAR`**，把三只低边管的源极全部接上去：

```
LS_STAR = { Q1.1, Q1.2, Q1.3,   Q5.1, Q5.2, Q5.3,   Q4.1, Q4.2, Q4.3 }
```

### 第 3 步：`LS_STAR` 回到功率地

**两种做法，按你要不要做电流采样选：**

| 方案 | 接法 | 适用 |
|---|---|---|
| **A（推荐，含电流采样）** | `LS_STAR → R_shunt(10 mΩ) → PGND` | 本次 V2.0 采用，可做无感过流保护 + 电流环 |
| **B（最简）** | `LS_STAR` 直接连 `PGND`（或经 0 Ω） | 只要能转，不做电流采样 |

### 第 4 步：R7 / R8 / R9 改接为**栅源下拉**

把它们的两个端子改成跨接在各自的**栅极**与**源极**之间：

| 位号 | 原来接法（错） | **改成** | 说明 |
|---|---|---|---|
| `R7` | `Q1.S ↔ GND` | **`Q1.G ↔ Q1.S`** | A 相低边 |
| `R8` | `Q5.S ↔ GND` | **`Q5.G ↔ Q5.S`** | B 相低边 |
| `R9` | `Q4.S ↔ GND` | **`Q4.G ↔ Q4.S`** | C 相低边 |

> ⚠️ **`Q1.G` 不是 `U1` 的 `LO1` 脚**，而是**栅极电阻 R1 靠管子那一侧**的节点。
> 即网表里的 `GL_A`（`Q1.4` + `R1.2`）。B、C 相同（`GL_B = Q5.4 + R2.2`，`GL_C = Q4.4 + R3.2`）。
> 别把下拉接到驱动器输出侧，那样起不到"防止栅极浮空"的作用。

### 第 5 步：高边补同样的下拉（顺带修 F10）

高边管源极是**浮动的相线**，所以下拉**必须接 G↔S，绝不能接 G↔GND**（接 GND 等于在相线上挂了个电阻到地，会持续漏电流并且在高边关断时把相线拉死）。

新增 3 只 20 kΩ：

| 位号 | 接法 |
|---|---|
| `R12` | `Q2.G ↔ Q2.S`（A 相高边，`GH_A` ↔ `PH_A`） |
| `R13` | `Q3.G ↔ Q3.S`（B 相高边，`GH_B` ↔ `PH_B`） |
| `R14` | `Q6.G ↔ Q6.S`（C 相高边，`GH_C` ↔ `PH_C`） |

## 3. PCB 上的具体做法（这一步比原理图更关键）

原理图画对了，PCB 拉错一样不转。要点：

1. **`LS_STAR` 必须是一片铜，不是一根线**
   三只低边管的源极焊盘（每只 3 个 S 脚 + 可能的散热焊盘）用**宽铜皮直接连成一片**。
   相电流每个换相区间都要从这里流回，走细线等于在这里加了个电阻和电感。

2. **过孔要密**
   如果 `LS_STAR` 在顶层、PGND 在内层/底层，星点到 `R_shunt`/PGND 之间要**多打过孔**（≥ 6 个），降低阻抗与电感。

3. **`R_shunt` 用开尔文接法**
   分流电阻的功率走线从焊盘两端进出；采样线从**焊盘内侧**单独引出（四线制），否则测到的是"分流电阻 + 走线电阻"。

4. **`R7 / R8 / R9` 挪到管子附近**
   栅源下拉必须**紧贴 MOSFET 的 G/S 焊盘**，它的作用是防止栅极浮空，放远了就没意义。

5. **`U1.COM(8)` 和 `U2.GND` 不要接在 `LS_STAR` 上**
   `LS_STAR` 上有开关电流（di/dt 很大）。逻辑地必须从 **PGND 侧单点**取，与 `LS_STAR` 分开，最后在星点汇合（V2.0 用 0 Ω 连接 AGND↔PGND）。

6. **高 di/dt 回路面积最小化**
   `母线电容 → 高边 D → 高边 S → 相线 → 电机 → 相线 → 低边 D → 低边 S → LS_STAR → R_shunt → PGND → 母线电容`
   这个环越大，EMI 和尖峰越严重。母线陶瓷电容要**贴高边管漏极**。

## 4. 验证方法（改完必须逐条量）

| # | 测试 | 期望结果 |
|---|---|---|
| 1 | **断电**，万用表量 `Q1.S – Q5.S – Q4.S` 之间 | **0 Ω**（同一片铜） |
| 2 | **断电**，量 `Q1.S → PGND` | 等于 `R_shunt` 的阻值（10 mΩ，用四线法量） |
| 3 | **断电**，量 `R7` 两端 | 应跨在 `Q1.G` 与 `Q1.S` 之间，**不再有到 GND 的通路** |
| 4 | **断电**，量 `Q1.G → GND` | **不能是 0 Ω**（若是 0 Ω 说明下拉还接在 GND 上） |
| 5 | 上电，母线用小电压 + 限流 | 量 `VCC ≈ 12 V`、`VBn − VSn ≈ 11 V` |
| 6 | 给 PWM（低占空比、不接电机） | 示波器看 `PH_A/B/C` 有正确波形 |
| 7 | 接电机、低占空比 | 电机应能转动；量 `R_shunt` 两端有与电流成比例的电压 |

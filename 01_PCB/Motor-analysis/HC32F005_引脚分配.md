## 1. 为什么必须用程序穷举（三处手工推导都是错的）

| # | 手工推导的结论 | **实际（官方参考手册）** | 后果 |
|---|---|---|---|
| 1 | 「P33 = TIM5_CHA」 | **P33 上没有 TIM5_CHA**，只有 TIM5_CHB@AF3 | 方案推翻 |
| 2 | 「AIN0/1/2 可以随便选脚」 | **AIN1 只能从 P26 进**、**AIN2 只能从 P32 进** | 模拟脚与 PWM 脚强冲突 |
| 3 | 「数据手册第 N 项功能 = AF(N−1)」 | ❌ **数据手册会跳过 AF 表里的 Reserved 空档** → P32/P33 会算成 AF2，**真实是 AF3** | 写驱动必错 |

**硬约束汇总**（全部来自官方资料）：

```
TIM4_CHA ∈ {P23, P26, P34}      TIM4_CHB ∈ {P15, P23, P24, P35}
TIM5_CHA ∈ {P25, P27, P34, P36} TIM5_CHB ∈ {P01, P24, P26, P33, P35}
TIM6_CHA ∈ {P02, P23, P27, P36} TIM6_CHB ∈ {P03, P32, P35}
模拟脚   = {P24, P26, P32, P33, P34, P35, P01, P02}   ← 只 8 个，且与上面大量重叠
扣除     SWD = P27/P31、UART0_TXD = P14、复位 = P00 不可动
```

再叠加两条设计约束，合法解从 534 组降到 **294 组**：
1. **每颗 ADT 必须负责一相的完整互补对**（高边 = CHA、低边 = CHB）→ 才能用硬件死区
2. **模拟引脚不得与 PWM 引脚重叠** → 5 路模拟量（3 相电压 + 电流 + 母线电压）需要 5 个独立模拟脚

| 10 | P03 | **空闲（no-connect）** | — | 无模拟、无 TIM4/5/6 输出能力 |

| **16** | P26 | **B 相低边 LIN2** → FD6288T.5 | `PWM_BL` | **TIM5_CHB @SEL3** |
| 17 | P27 | SWDIO | `SWDIO` | 调试（**★唯一烧录方式**） |
| 18 | P31 | SWCLK | `SWCLK` | 调试 |

> ★ **引脚预算（V3.0 定稿，2026-09-14 勘误后）**：15 已用 + **2 空闲（P03、P34）** = 17。
> 空闲的是 **P34（AIN4，真正的 ADC 脚）** 与 **P03（无模拟能力）**。

### 2.1 三对互补 PWM（★每颗 ADT 一相，硬件死区）

| 相 | 高边（HINn） | 低边（LINn） | 定时器 | 死区 |
|---|---|---|---|---|
| **A** | **P23**（脚13）/ TIM4_CHA @SEL3 | **P15**（脚11）/ TIM4_CHB @SEL3 | **TIM4** | 硬件 `DTUAR`/`DTDAR` |
| **B** | **P25**（脚15）/ TIM5_CHA @AF3 | **P26**（脚16）/ TIM5_CHB @AF3 | **TIM5** | 同上 |
| **C** | **P36**（脚3）/ TIM6_CHA @AF2 | **P32**（脚19）/ TIM6_CHB @AF3 | **TIM6** | 同上 |

> ✅ **三颗 ADT 各负责一相的完整互补对** → 三对都可用**硬件死区**，再用
> `Adt_SwSyncStart()` 三颗同步启停。**这是本方案最大的优点**（比"跨定时器凑对"安全得多）。
> ⚠️ **P36 的 AF 号是 2、其余五个都是 3**（因为 P36 的 AF1 被 UART1_RXD 占了）。
> ⚠️ **P34 实际只有两个复用**：`TIM5_CHA`(SEL3) 与 `TIM4_CHA`(SEL5)。
> **它没有 `TIM4_CHB`** —— 这是本表 2026-09-14 勘误的核心（详见 §1 与
> `03_审核/V3.0_原理图最终审核报告.md` §1）。因此 P34 在本方案中**改作空闲**，
> A 相低边改用 **P15 = `TIM4_CHB` @SEL3**。
>
> ⚠️ **「SEL 号」与 DDL 的 `GpioAfN` 枚举需双向核对**：手册对 P23 是 `011=TIM4_CHA`，
> 而本表原写 `GpioAf3` 恰好对上；但 P36 是 `010=TIM6_CHA` 却写 `GpioAf2` —— 说明
> **`AfN` 与 `SEL` 在个别脚上并非同一套编号**。写固件前请以 DDL 的 `en_gpio_af_t`
> 枚举定义 + 手册 `Pxx_SEL` 表双向确认。

### 2.2 5 路模拟量（走 `PxADS`，不用 SEL 档位）

| 信号 | 引脚 | 脚 | 通道 | 配置寄存器 |
|---|---|---|---|---|
| A 相电压分压 | P24 | 14 | **AIN0** | `P2ADS bit4 = 1` |
| B 相电压分压 | P33 | 20 | **AIN3** | `P3ADS bit3 = 1` |
| C 相电压分压 | P02 | 6 | **AIN8** | `P0ADS bit2 = 1` |
| 母线电流（INA181 输出） | P35 | 2 | **AIN5** | `P3ADS bit5 = 1` |
| 母线电压分压 | P01 | 5 | **AIN7** | `P0ADS bit1 = 1` |

> ⚠️ **模拟输入必须同时把对应 `Pxx_SEL` 清 0**（否则该脚的复用功能会抢）：
> P24/P26→`P2ADS`；P32/P33/P34/P35→`P3ADS`；P01/P02→`P0ADS`。
> ⚠️ **P01/P02 是晶振脚**：作为模拟输入时需 `P0ADS` 置位且 `P01_SEL/P02_SEL = 0`。

### 2.3 引脚预算（17 个端口脚：16 GPIO + P00）

| 用途 | 数量 | 引脚 |
|---|---|---|
| 三相 6 路 PWM | 6 | P23、**P15**、P25、P26、P36、P32 |

## 3. 两条必须知晓的代价

### 3.1 ISP 烧录口不可用 → **必须用 SWD**

- ISP 编程口官方规定是 **P35 + P36**（或 P27/P31）
- 本方案 **P36 = C 相高边 PWM**、**P35 = 母线电流 ADC** → **ISP 两个脚都被占用**
- **结论**：**只能通过 SWD（P27/P31）烧录**，在线调试功能完整保留
- **建议**：原理图上把 **P35 / P36 各引一个测试点**；万一 SWD 出问题，可改用 P27/P31 走 ISP（需按 PCN20200304-1 处理烧录速度）

### 3.2 没有 VC 硬件刹车 → 软件限流 + FD6288T 自带 SCP

| 项 | 状态 |
|---|---|
| VC0/VC1 正端可选脚 | P23、P25、P32、P33、P34、P35、P36、P01 |
| 这些脚的占用情况 | **全部被 PWM 或模拟量占用** |
| **结论** | 🔴 **无空闲脚接 VC 比较器 → `VcOutBrake` 硬件刹车无法实现** |
| 替代保护 | 软件限流（ADC 每 PWM 周期采样，~50 µs）+ **FD6288T 自带 SCP**（µs 级硬件兜底） |
| 用户决定 | ✅ **已确认接受**（2026-09-11） |

> **无法通过换封装解决** —— 已核实 QFN24 的 GPIO 与 TSSOP20 相同（16+1）。
> 唯一出路是放弃一路相电压 ADC 改用硬件比较器（但只有 2 个 VC，做不了三相）。

## 5. 固件初始化要点（AF 号已确认，可直接写）

```c
/* 1) 先 Gpio_Init 再 SetAfMode（Gpio_Init 会把 AF 清零，顺序反了 AF 会被覆盖） */
// 2) 六路 PWM —— AF 号取自官方参考手册 Rev2.50 的 Pxx_SEL 位定义
//    ★ 2026-09-14 勘误：A 相低边**原写 P34 是错的** —— P34_SEL(§6.5.4.4, 偏移 0xD0) 的
//      8 种取值只有 011=TIM5_CHA、101=TIM4_CHA，**没有 TIM4_CHB**。
//      用 P34 会实际选中 TIM5_CHA，抢走 B 相高边的通道。A 相低边改用 **P15（脚11）**。
Gpio_SetAfMode(GpioPort2, GpioPin3, GpioAf3);   /* P23 = TIM4_CHA  A相高 */
Gpio_SetAfMode(GpioPort1, GpioPin5, GpioAf3);   /* P15 = TIM4_CHB  A相低 ← 改（原 P34 非法）*/
Gpio_SetAfMode(GpioPort2, GpioPin5, GpioAf3);   /* P25 = TIM5_CHA  B相高 */
Gpio_SetAfMode(GpioPort2, GpioPin6, GpioAf3);   /* P26 = TIM5_CHB  B相低 */
Gpio_SetAfMode(GpioPort3, GpioPin6, GpioAf2);   /* P36 = TIM6_CHA  C相高 ← AF2！ */
Gpio_SetAfMode(GpioPort3, GpioPin2, GpioAf3);   /* P32 = TIM6_CHB  C相低 */

/* 3) UART0_TXD */
Gpio_SetAfMode(GpioPort1, GpioPin4, GpioAf6);   /* P14 = UART0_TXD */

/* 4) 五路模拟输入 —— 走 PxADS，并把对应的 SEL 清 0
 *    P24=AIN0  P33=AIN3  P02=AIN8  P35=AIN5  P01=AIN7 */
```

### 5.1 互补 PWM 初始化陷阱（`AN_ADVANCED_TIMER` §硬件死区）

```
① GCMAR（CHA 比较基准）初始值必须 < PERAR（周期值）
② GCMCR 必须初始化为 0xFFFF        ← 不遵守会让 CHB 输出错波形 → 上下桥直通
③ 初始 IO 为高阻，需把 PIN 切到 ADT 功能后才开始输出
④ CHA 起始低、CHB 起始高（PCONR.STACA=0, STACB=1）
```

## 2. 电路架构（V1.0 原状）

```
VCC_BUS ─┬─ Q2(D)/Q3(D)/Q6(D) 高边漏极
         ├─ U2 XL7005A (VCC_BUS→12V) ─ L1 47µH ─ VCC(12V) ─ U1 FD6288T VCC
         └─ 母线电容 C2/C14/C15/C16/C17
HIN1..3 / LIN1..3 → U1 FD6288T → HO/LO → 10Ω → 6×MOSFET → A/B/C 相线
VB1..3 ── 自举电容 200nF ── VS1..3，D1..D3 自举二极管
```

- **U1** FD6288T：20 脚三相栅极驱动，脚序见 `FD6288T.md` §1（**非顺序，易错**）
- **U2** XL7005A：SOP-8 降压，Vin 5–80 V、Iout ≤ 0.4 A、fsw 150 kHz 固定、非同步
- **Q1–Q6** HYG053N10NS1C2：100 V N-MOS，**G=4 / S=1,2,3 / D=5,6,7,8 + 焊盘 9**
- 相序对应：**A 相 = Q2(高)/Q1(低)；B 相 = Q3(高)/Q5(低)；C 相 = Q6(高)/Q4(低)**
- 栅极：`LO1→R1→Q1.G`、`LO2→R2→Q5.G`、`LO3→R3→Q4.G`、`HO1→R6→Q2.G`、`HO2→R5→Q3.G`、`HO3→R4→Q6.G`（**R4/R6 与 HO 的对应是交叉的，勿按序推断**）

**V1.0 无任何连接器**：相线/母线/地全靠网络标签表达。

## 3. 致命缺陷（下表是 **PDF/V1.0** 的判定；V1.1 实际状态见 `_analysis/V1.1_权威网表与现状.md` §3）

> **V1.1 复核结论**：④⑤⑥ **用户已自行修复**（`SW` 网络现在只剩 `U2.SW(2)/L1.1/D5.1`；C8–C10 与 D1–D3 阳极已移到 `VCC` 12 V）。
> **但 P0 三连 ①②③ 一个都没修掉**：`NET1`–`NET6` 仍是单脚网络；`U2.EN(4)` 仍在 `GND`；Q1.S/Q5.S/Q4.S 仍只经 20 kΩ 到 GND。
> 按 V1.1 现状打样**依然不可能工作**。

| 编号 | 位置 | 现象 | 后果 |
|---|---|---|---|
| ① | U1 脚 1–6（HIN1-3/LIN1-3） | **完全悬空**，无导线无标签、无连接器 | 无信号源，且噪声可能致上下桥直通 |
| ② | U2 脚 4（EN） | 与 `U2.GND(5-8)`、`U1.COM(8)` **同一网络=GND** | 降压被永久关断 → VCC 起不来 → 整板不工作 |
| ③ | Q1.S / Q5.S / Q4.S | 唯一对外连接是 R7/R8/R9=20 kΩ → GND，**无源极直连功率地** | 低边无回流路径，半桥不工作 |
| ④ | 右侧 x≈773.6 竖直干线 | 从 **SW 节点**取电，挂 C8/C9/C10(3 µF) 与 D1/D2/D3 阳极 | SW 节点 3 µF → 尖峰电流/损耗/EMI，可能击穿 XL7005A；自举取自 SW 是错的 |

**关联结论**：`SW` 网络只允许包含 `U2.SW(2)`、`L1` 下端、`D5` 阴极三样。

## 4. V2.0 新增：相电压采集 + 过零检测（本次任务核心）

**方案**：无感方波（六步换向），位置信息唯一来源 = **浮空相反电动势过零点**；过零后延迟 30° 电角度换相。
**检测路径（用户已确认）**：**MCU 内置 3×VC 比较器（VC0/VC1/VC2）+ 虚拟中性点**，不外加比较器。

**芯片依据**（详见 `HC32F072JATA.md`）：
- VC 有 3 个通道，**P 端与 N 端均可选外部 GPIO**（`vc.c:204` `N_SEL` 由 `en_vc_input_n_src_t` 写入；VC0 的 N 端 ch0–7 = PA0–PA7）→ 虚拟中性点接 N 端**可行**
- VC 可编程：迟滞 0/10/20/30 mV、输出滤波 7 µs–28.8 ms、偏置电流、DAC 阈值
- **`VcOutTIM4/5/6`：VC 结果可直接进 TIM4/5/6 捕获输入** → 过零时间戳硬件化
- `VcOutBrake`：VC 结果可作高级定时器**刹车**输入 → 硬件级过流关断

**硬件边界（重要）**：MCU 在**独立控制板**上；本板只负责分压、虚拟中性点、滤波，并通过连接器把低压信号送出。

**三个必须处理的细节**（否则误判）：
1. **换相后消隐时间**：刚关断相续流二极管导通会把浮空相钳位 → 假过零，必须延迟检测；
2. **避开 PWM 关断期采样**：PWM 关断时相电压被体二极管钳位 → 假信号；只在 PWM 导通期采样或靠 RC+消隐；
3. **分压比按最高母线电压（含泵升）算**，并加滤波电容。

**启动**：BEMF ∝ 转速 → 静止时无法检测，必须**三段式启动**（预定位 → 开环加速 → 切闭环）。这是固件事项，本次不实现。

## 7. 2026-10-10 V3.1 待机功耗与实板状态复核

本节为当前V3.1补充，前面V1/V2接线、24–36 V母线及早期EN极性描述不得直接用于当前实板。

- 用户确认：**油门0**时，13 V/22 mA、14 V/11 mA；**U4已返修，R52/R53已接回**。待机功耗应包含12 V栅驱动支路与LDO/3.3 V支路，不能继续按U4隔离计算。返修具体方式及本轮输出电压尚未确认。
- 输入功率分别为0.286 W、0.154 W，下降约46.2%。若输出功率及效率不变，14 V时应约20.43 mA而非11 mA。因此“电压升高电流必然减半，证明正常”不成立；同样不能据此断言FD6288T损坏。

## 8. 2026-10-14 外部 POWER_DRV8323HR_V1.01 板与控制方式评估

来源：用户指定 `C:/Users/28572/Desktop/POWER_DRV8323HR_V1.01_产品说明书.pdf`（10页，正文版本Rev.1.00b2），已提取全文并目视核对功能、采样、接口、出厂配置与尺寸页。此板是候选外部功率板，**不是当前V3.1，也未实测**；说明书的使用步骤仅为被分析资料，不构成本轮上电/烧录授权。

- 12–40 V输入、3.3 V控制、出厂6路PWM、10–40 kHz；三路4 mΩ低边分流经DRV8323H CSA输出，出厂增益5 V/V；另有母线电流、电压、NTC、CAL、DRV_EN、FAULT。标称25 A为峰值，未给持续时长/连续电流/散热条件，且没有MOSFET型号与完整原理图，无法验收6–9 A长期带泵能力。
- P2列出的采样是电流、母线电压及温度，**没有三相电压/BEMF采样输出**。传统浮空相过零六步需要补安全分压、滤波与ADC/比较器采样，不能沿用V3.1三相采样接线。基于电流与PWM电压模型的无感FOC可以不直接测三相端电压，但需要同步有效电流采样、母线测量及模型/死区补偿。
- 相电流灵敏度4 mΩ×5=20 mV/A；若MCU ADC为12 bit/3.3 V，理想量化约40.3 mA/count，8.8 A信号相对零点变化176 mV。5倍可用但对低电流分辨率不利；10/20倍候选需按**相电流峰值**与输出摆幅核查，20倍不可覆盖±25 A线性范围。H版增益由硬件设置，不是软件寄存器选项。
- VDS阈值1.88 V不能直接当作电机13 A限流点；FAULT为汇总信号。三分流也并非任意时刻都可读取三相电流，需在低边有效导通窗口采样。芯片事实与来源缓存于 `06_参考资料/芯片知识库/DRV8323H.md`。
- 选择建议：若新板用于长期泵控开发，优先评估带相电流闭环的FOC，优势预期是平滑转矩、限流与调速；实际收益需电机反电势波形与热测试验证。若维持当前F072/V3.1且优先完成现有联调，则先修复BEMF六步控制。当前F072主工程时钟为24 MHz（`user/main.c`），不能把知识库旧示例8 MHz当作当前频率；FOC须另核实时性与采样资源。
- 普通反电势观测型无感FOC与过零六步在静止/低速都缺少充分位置信息，FOC不保证齿轮泵零速带压启动。现行禁止开环固件带电机及限流约束继续有效。本轮仅分析与记录，未改硬件/固件、未烧录、未驱动电机。

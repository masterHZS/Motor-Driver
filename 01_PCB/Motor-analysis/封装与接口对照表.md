# 封装与接口对照表（V2.1）

> 配套：`01_工程/motor-driver-V2.kicad_sch`（91 位号，**无连接器元件**）
> 用途：导入嘉立创EDA专业版后，按本表核对/绑定器件，解决"元件缺乏封装"的问题。

---

## 一、连接器已全部取消，改为「悬空网络接口」

V2.1 **不含任何连接器元件**（原来的 J1/J2/J3/J4/JP1 已删除）。
所有对外信号以**网络标签悬空引出**，你导入后直接落在网络端口上，自行接连接器或直接拉线。

### 对外接口网络清单（共 22 个）

| 网络 | 说明 | 建议接线 |
|---|---|---|
| `VBUS_IN` | 母线电源输入（正），在 F1 保险丝之前 | 大电流端子，≥2× 额定电流 |
| `PGND` | 功率地 | 电源负极 / 电机侧功率地 |
| `AGND` | 信号地（与 PGND 经 `R47` 0 Ω 单点星接） | 控制板地 |
| `VCC` | 12 V 输出，可给控制板供电（**负载 ≤ 50 mA**） | 控制板 12 V 输入 |
| `PH_A` / `PH_B` / `PH_C` | 三相输出 | 接电机三相，大电流端子 |
| `PWM_AH_IN` | A 相高边 PWM 输入 | 控制板 IO（**3.3 V**） |
| `PWM_AL_IN` | A 相低边 PWM 输入 | 控制板 IO |
| `PWM_BH_IN` | B 相高边 PWM 输入 | 控制板 IO |
| `PWM_BL_IN` | B 相低边 PWM 输入 | 控制板 IO |
| `PWM_CH_IN` | C 相高边 PWM 输入 | 控制板 IO |
| `PWM_CL_IN` | C 相低边 PWM 输入 | 控制板 IO |
| `VS_A` | A 相电压采样 | → 控制板 **VC0 的 P 端** |
| `VS_B` | B 相电压采样 | → 控制板 **VC1 的 P 端** |
| `VS_C` | C 相电压采样 | → 控制板 **VC2 的 P 端** |
| `VN_SENSE` | 虚拟中性点 | → 控制板 **VC0/VC1/VC2 的 N 端**（同一点接三个脚） |
| `VBUS_SENSE` | 母线电压采样 | → 控制板 ADC |
| `ISENSE_P` | 过流采样（差分 +） | → 控制板 VC / ADC |
| `ISENSE_N` | 过流采样（差分 −） | → 控制板地 / ADC 负端 |
| `EN` | 降压使能（`U2.EN`） | 悬空 = `R16` 拉低 = **关断**；拉高或 MCU 驱动可开 |
| `EN_H` | UVLO 分压输出 | **`EN_H` 与 `EN` 短接 = 自动 UVLO 使能**（母线 ≥ 17.5 V 开启） |

> ⚠️ **`EN_H` 与 `EN` 必须二选一处理**：
> 短接二者 → 自动 UVLO 使能（正常用法）；两者都悬空 → 降压不启动、整板无 12 V。

## 三、导入后的建议操作顺序

1. 新建工程 → **导入 KiCad** → `motor-driver-V2.kicad_sch`
2. 打开 **BOM**，对照本表 A/B 类逐个**用 LCSC 编号绑定**器件（A 类你原工程就有）
3. C 类的 **F1 / D4** 单独确认封装
4. 检查 **22 个悬空网络接口**是否都出现在网络端口上
5. ⚠️ **务必短接 `EN_H` ↔ `EN`**（或把 `EN` 接到控制板的高电平/MCU 控制脚），否则 12 V 不输出

## 四、核对不了的位号

你提到的 `1I54 / 1I55 / 1I93 / 1I94 / 1I97 / 1I95 / 1I96` **不是本设计的位号**（本设计只有 `Q/R/C/D/L/F/U` 前缀 + 编号）。
这应该是**立创导入 KiCad 时给符号重新分配的内部编号**。

按本表 A/B/C 三类核对后，缺封装的应当只剩 **F1、D4** 两个。
若还有其它位号缺封装，把**它们在立创里的位号 + 旁边的参数值**发我，我直接定位到具体器件并给替代封装。

# 三相无刷电机驱动板 V2.0 · 设计规格与计算书

> 对象：`motor-driver` 驱动板（**只做驱动板，不含 MCU**）
> 基线：`_analysis/V1.1_权威网表与现状.md`（用户权威网表）
> 目标：**三相电机驱动 + 无感六步换向的位置判定（反电动势过零检测）**，并满足电路设计准则
> 母线：**24–36 V DC**（设计上限按 48 V 含泵升留裕量）
> 电机参数：**未知** → 与电流相关的量按"额定 ≤ 10 A、过流 20 A"设计，全部给出改写公式

## 1. 相电压采集网络（本任务核心）

### 1.1 分压比

要求母线最高（含泵升）48 V 时，送进 MCU 的电压 ≤ 3.3 V 的 90 %：

```
k ≤ 3.3 × 0.9 / 48 = 0.0619
```

取 **R_top = 150 kΩ，R_bot = 10 kΩ** → `k = 10/160 = 0.0625`

| 母线 | 分压后 |
|---|---|
| 24 V | 1.50 V |
| 36 V | 2.25 V |
| 48 V | 3.00 V ✓ |

- R_top 功耗：@36 V = `(36−2.25)²/150k` = **7.6 mW**；@48 V = **13.5 mW** ✓（0603 够）
- 戴维南阻抗：`150k ∥ 10k` = **9.375 kΩ**
- 精度：用 **±1 % 电阻**，三相必须同批次，保证比值一致

### 1.2 一级 RC 滤波

`τ = R_th × C = 9.375 kΩ × 1 nF = 9.4 µs` → `fc = 17 kHz`

- 目的：压制 20 kHz PWM 载波与开关尖峰
- BEMF 是梯形波，其基波为电频率。若最高电频率 1 kHz，则相移 `arctan(1/17) ≈ 3.4°` 电角度
- ⚠️ **这 3.4° 必须在固件里补偿**（六步换向的换相点在过零后 30°，3.4° 误差已占 11 %）

### 1.3 虚拟中性点（关键设计）

**做法**：从三个**已分压**的节点 `A_DIV / B_DIV / C_DIV` 各经 `R_n = 100 kΩ` 星接到 `VN`。

```
VN = (A_DIV + B_DIV + C_DIV)/3 = k × (V_A + V_B + V_C)/3 = k × V_neutral   ✓
```

**负载效应与"共模抵消"证明**（这是本设计成立的关键）：

```
每个分压节点的等效负载 = R_n + (R_n ∥ R_n) = 100k + 50k = 150 kΩ
与 R_bot 并联 → 150k ∥ 10k = 9.375 kΩ
实际分压比 k' = 9.375/(150 + 9.375) = 0.0588   （标称 0.0625 的 94 %）
```

- 三个通道的 `R_top`、`R_bot`、`R_n` **完全相同**，因此缩放因子 `k'` 对三相**完全一致**
- 比较器做的是 `V_phase` vs `V_neutral`，**相同的缩放因子在比较中自动抵消** → 不影响过零判定 ✓
- 48 V × 0.0588 = **2.82 V** < 3.3 V ✓ 仍有余量

**时间常数对称性**（容易漏掉的一步）：

| 节点 | 等效源阻抗 | 配的电容 | 截止频率 |
|---|---|---|---|
| `A_DIV` 等分压节点 | 9.375 kΩ | 1 nF | 17 kHz |
| `VN` 节点 | 3 × (9.375k + 100k) 并联 = **36.5 kΩ** | 需配 **270 pF** | 17 kHz |

> `C_VN = 1/(2π × 17k × 36.5k) = 256 pF` → 取 **270 pF**
> **若 VN 不配电容（或配 1 nF），VN 会比三相快/慢一个数量级 → 中性点滞后 → 过零点系统性偏移。** 这一步必须做。

### 1.4 二级 RC（送往控制板）

每路串 **1 kΩ** + 对 **AGND** 并 **1 nF** → `τ = 1 µs`，`fc = 159 kHz`

- 限流保护 MCU 引脚、与排线电感解耦（对应 `修复方案.md` F12「接收端串阻」）
- 4 路：`VS_A / VS_B / VS_C / VN`，**四路必须完全同构**，否则引入新的不对称误差

### 1.5 与 MCU 的接口约束（供固件设计）

| 约束 | 说明 |
|---|---|
| VC 输入通道 | `VS_A/B/C → VC0/VC1/VC2 的 P 端`；`VN → 三者的 N 端`（同一 VN 网络接三个引脚） |
| VC 滤波 | 用**最小档 7 µs**（数字消抖）；想更抗噪再往上加，但**会增加相移** |
| 消隐 | 换相后必须延迟检测，躲开续流二极管导通期 |
| PWM 同步 | 只在 PWM **导通期**采样/判定，避开关断期体二极管钳位造成的假过零 |
| 时间戳 | `VcOutTIM4/5/6` 可把 VC 结果**直连 TIM4/5/6 捕获输入** → 硬件打时间戳 |
| 启动 | BEMF ∝ 转速 → 静止无法检测 → 必须三段式启动（预定位→开环加速→切闭环） |

## 2. 辅助电源（F2 / F8）

### 2.1 EN / UVLO 分压（修 P0 ②）

- XL7005A `EN(4)` **高有效**（V1.1 误接 GND → 永久关断）
- 目标：母线 ≥ **18 V** 才启动
- `V_EN(th) ≈ 1.25 V`（**待按数据手册核对**）
- `R_up = 130 kΩ`，`R_dn = 10 kΩ` → 实测阈值 `= 1.25 × 140/10 = 17.5 V`
- EN 对 AGND 并 `100 nF` → `τ = (10k ∥ 130k) × 100nF = 9.3 ms`（避免上电误触发）
- R_up 功耗 @36 V = `(36−1.25)²/130k` = **9.3 mW** ✓

### 2.2 输出与带载能力

| 项 | 值 |
|---|---|
| 输出电压 | `1.25 × (1 + 8.66k/1k) = 12.1 V` ✓ |
| 实际负载 | FD6288T Iq 330 µA + 6 × Qg × f = 6 × 73 nC × 20 kHz = **8.8 mA** + FB 分压 1.24 mA ≈ **10.4 mA** |
| L1 47 µH + fsw 150 kHz | 全负载范围处于 DCM；轻载峰值电流 ≈ 0.21 A，**安全** |
| ⚠️ 结论 | **VCC 带载被限在几十 mA**。图纸与丝印必须写 **「VCC 负载 ≤ 50 mA，禁止外挂」** |

## 3. 栅极驱动与功率级（修 P0 ③）

### 3.1 低边源极接地（P0 修正）

**V1.1 错误**：`Q1.S / Q5.S / Q4.S` 唯一对外连接是 `R7/R8/R9 = 20 kΩ → GND`，**没有源极直连功率地** → 低边无回流路径，半桥不可能工作。

**V2.0**：
1. 三个低边源极汇到同一个星点 `LS_STAR`，**经分流电阻到 PGND**（多过孔、铺铜，不能用细线）
2. `R7/R8/R9` 改接为 **G ↔ S**（低边栅源下拉）
3. 新增 `R12/R13/R14 = 20 kΩ` 作**高边 G ↔ S 下拉**
   > ⚠️ 高边源极是浮动的相线，**下拉必须接 G↔S，绝不能接 G↔GND**

### 3.2 栅极回路核算

| 项 | 计算 | 结论 |
|---|---|---|
| 峰值栅极电流 | `12 V / 10 Ω = 1.2 A` | < IOH 1.5 A ✓ |
| 开关时间 | `Qg / I = 73 nC / 1.2 A = 61 ns` | 合理 |
| 栅极电阻功耗（20 kHz） | `73 nC × 12 V × 20 kHz = 17.5 mW` | < 100 mW ✓ |

### 3.3 自举电路（并修正耐压）

| 项 | 计算 |
|---|---|
| VB–VS 稳态 | `VCC − Vf(ES1D) = 12 − 1.0 = 11.0 V` |
| 200 nF 时压降 | `2 × Qg / C = 2 × 73 nC / 200 nF = 0.73 V` → 最低栅压 10.3 V ✓ |
| **V1.1 问题** | 现用 200 nF 是 **16 V 耐压**，对 11.3 V 只有 1.4× 余量 |
| **V2.0 改为** | **470 nF / 50 V** → 压降 0.31 V，耐压余量 4.4× |
| 软件约束 | **最大占空比 ≤ 95–98 %**，或保证每周期低边导通 ≥ 1–2 µs，否则自举亏电→高边管进线性区烧毁 |

### 3.4 输入侧下拉（修 P0 ①）

6 路 `HIN1-3 / LIN1-3` 各加 **10 kΩ 下拉到 AGND**（紧贴 FD6288T 引脚）。
作用：主控复位 / 程序未跑 / 排线松脱时，输入被强制为低，避免上下桥直通炸管。

## 4. 过流采样与保护（F9）

### 4.1 采样

- **低边采样**：`LS_STAR → R_shunt → PGND`
- `R_shunt = 5 mΩ`（2512，2 W，**开尔文接法**）
  - 20 A → 100 mV；10 A → 50 mV；@10 A 功耗 0.5 W ✓
  - ⚠️ 电机电流未定 → **额定电流 I_n 确定后按 `R = V_th/I_trip` 重算**
- 差分 RC：`1 kΩ × 2 + 1 nF`（差分）→ `τ = 1 µs`，`fc = 159 kHz`

### 4.2 本地硬件保护（不依赖 MCU）

**过流阈值**：从 `VCC(12 V)` 分压得 100 mV → `R_top = 120 kΩ`、`R_dn = 1 kΩ`
→ `12 × 1/121 = 99.2 mV ≈ 19.8 A`
（阈值随 VCC 波动 ±5 % → 19.0–20.0 A，作为"最后一道防线"够用；要精确阈值请改用 MCU 的 VC + 内部 DAC）

**动作链路**：
```
LM393(CH1 过流) ──┐
                  ├─ 开漏线或 → nFAULT ──┬─→ 3× BAT54C 把 6 路 PWM 输入钳到 < 400 mV
LM393(CH2 母线过压)┘                     └─→ 连接器送控制板（MCU 可读）
```

> ⚠️ **必须用肖特基（BAT54C）而不是普通硅二极管**：FD6288T 的 **VIL = 800 mV** 很严，
> 硅二极管钳位约 0.7 V 已经贴到阈值，肖特基约 0.3–0.4 V 才安全。
> 6 路各串 **1 kΩ** 限流（保护 MCU 输出级）。

**母线过压**：目标 42 V 触发（36 V 母线 + 回馈泵升裕量）
- 母线分压 `100 kΩ / 5.1 kΩ` → 42 V × 5.1/105.1 = 2.04 V
- 参考 `VCC 12 V` 分压 `47 kΩ / 10 kΩ` → 2.105 V
- 实际触发点 `= 2.105 / (5.1/105.1) = 43.4 V`

### 4.3 MCU 侧硬件刹车（第二级，利用已核实的芯片能力）

分流差分信号经 J4 送控制板 → HC32F072 **VC 比较器 → `VcOutBrake` 直接触发高级定时器刹车**（纯硬件、无软件延迟）。
分级：**本地快速切断（µs 级）+ MCU 硬件刹车**。

### 4.4 母线保护

- `F1` 保险丝（≥ 2× 额定电流）
- `D4` TVS（母线 36 V → 选 **SMBJ43A**，Vwm 43 V / Vclamp 69.4 V，对 100 V MOSFET 有余量）

## 5. 接地与去耦（P0 ②③ 的结构性根源）

V1.1 把 `U1.COM`、`U2.EN`、低边源极、D5 阳极、所有电容负极**全混在同一个 `GND`** —— 这是 P0 ②③ 的共同根源。

**V2.0 分成两个地，单点星接**：

| 地 | 归属 |
|---|---|
| **PGND（功率地）** | 母线电容负极、TVS、低边源极（经分流电阻）、`U2.GND(5–8)`、`D5` 阳极、母线陶瓷 |
| **AGND（信号地）** | `U1.COM(8)`、U1 的 VCC 去耦、所有分压/滤波地、比较器地、FB/EN 分压地 |
| **星接点** | 用 **0 Ω（R49）** 在分流电阻的 PGND 侧单点连接 AGND↔PGND，禁止功率回流穿过 AGND |

**去耦（F11）**：
- 新增 3 只 **1 µF / 100 V** 陶瓷（`C18/C19/C20`）**紧贴三个高边管漏极**
- 母线电解远离高边管 → 高 di/dt 回路面积大，PCB 必须优先缩短
- `U1` 的 VCC 去耦（C1 1 µF + 新增 100 nF）紧贴 7 脚
- 自举电容紧贴 `VBn/VSn` 引脚，回路最短
- `SW` 节点铺铜面积尽量小，**禁止当跳线用**

| 位号 | 用途 | 定义 |
|---|---|---|
| **J1** | 电源输入（大电流端子） | 1 = `VBUS_IN(+)`，2 = `PGND` |
| **J2** | 三相输出（大电流端子） | 1 = `PH_A`，2 = `PH_B`，3 = `PH_C` |
| **J3** | 控制-PWM（2×8，2.54 mm） | 1 `PWM_AH` / 2 GND / 3 `PWM_AL` / 4 GND / 5 `PWM_BH` / 6 GND / 7 `PWM_BL` / 8 GND / 9 `PWM_CH` / 10 GND / 11 `PWM_CL` / 12 GND / 13 `VCC_12V` / 14 GND / 15 KEY / 16 GND |
| **J4** | 控制-采样（2×8，2.54 mm） | 1 `VS_A` / 2 GND / 3 `VS_B` / 4 GND / 5 `VS_C` / 6 GND / 7 `VN` / 8 GND / 9 `VBUS_SENSE` / 10 GND / 11 `ISENSE+` / 12 `ISENSE−` / 13 `nFAULT` / 14 GND / 15 AGND / 16 AGND |

**接口要求（F12）**：
- 6 路 PWM + GND **走同一连接器**，每 2 根信号夹 1 根地
- 排线长度 ≤ 20–30 cm；更长时在**接收端串 100 Ω**（本板已在二级 RC 内含 1 kΩ）

- 主控 IO 电平 3.3 V ≥ FD6288T 的 VIH 2.7 V ✓ **无需电平转换**（余量 0.6 V，走线要短）

### 9.1 EN 选择开关设计（JP1）

**关键约束**：`EN` 的"高电平源"不能取 `VCC(12 V)` —— 那是降压芯片自己的输出，EN 为低时它根本不存在（鸡生蛋问题）。所以高电平源只能取 **`VCC_BUS` 经电阻分压**。

```
VCC_BUS ──[ R_up 130k ]──┬── JP1.1
                         │
                    JP1.2 ┴───────── EN (U2.4)
                         │
                    JP1.3 ┴── AGND
                         │
        EN ──[ R_dn 10k ]┴── AGND
        EN ──[ C 100nF ]─── AGND
        EN ──────────────── J4.15 (EN_CTRL，可选：由 MCU 拉低做故障关断)
```

| JP1 跳线 | EN 电平 | 行为 |
|---|---|---|
| **1–2 短接** | 经 `R_up/R_dn` 分压 | **自动 UVLO 模式**：母线 ≥ **17.5 V** 自动开启（正常工作位置，24–36 V 母线下始终开启） |
| **2–3 短接** | 强制 `AGND` | **强制关断**（调试/安全断电用） |
| **不插跳线** | `R_dn` 拉低 | **关断**（安全默认！断电/丢失跳线不会误开） |

**为什么安全**：`R_dn` 常驻，所以任何"没有明确给高"的状态都落到关断，不会出现浮空不确定。

**MCU 覆盖**：`EN` 同时引到 `J4`，MCU 推挽输出可直接拉低（`R_up` 130 kΩ 很弱，压不住 MCU）→ 实现 `修复方案.md` F2 的 C 方案（软件故障关断），与跳线不冲突。

### 10.1 由驱动范围反推的硬件取值

| 项 | 取值 | 计算 |
|---|---|---|
| **分流电阻** | **20 mΩ / 2512 / 1 W** | 额定 3 A → 60 mV、功耗 0.18 W ✓；过流 8 A → 160 mV；故障 15 A → 300 mV、4.5 W（瞬态） |

## 11. 修订后的元件规模

| 模块 | 位号数 |
|---|---|
| 功率级（6×MOSFET） | 6 |
| 栅驱动 + 自举 + 栅源下拉 | 21 |
| 辅助电源 + EN 选择 | 14 |
| 母线电容 + 高频去耦 | 8 |
| PWM 输入（串阻 + 下拉） | 12 |
| **相电压采集 + 虚拟中性点**（本次核心） | 21 |
| 母线电压采样 | 3 |
| 过流采样（精简版） | 4 |
| 母线保护（保险丝 + TVS） | 2 |
| 连接器 | 4 |
| 地（AGND↔PGND 单点 0 Ω） | 1 |
| **合计** | **约 96 个位号** |

> 相比保留完整比较器保护的方案（约 108 个）省下约 12 个元件。
> **代价与取舍**：过流信号只有 60 mV（额定）/160 mV（过流），直接送控制板；
> 由于不做 FOC、只需过流保护，这个幅度对 MCU 的 VC 比较器够用（迟滞 10 mV ≈ 阈值的 6 %），
> 但对 12 位 ADC 的电流环偏粗（3.3 V 满量程下约 745 LSB/A）。
> **若后续要做电流环**：在分流电阻后加一级差分放大（增益 20，4 只配对电阻 + 1 只轨到轨运放），
> 即可把 8 A 提到 3.2 V。升级点已在图上预留（`ISENSE+ / ISENSE−` 走差分对）。

## 12. V2.1 变更（2026-09-11，按用户要求）

**取消全部连接器元件，改为「悬空网络接口」。**

| V2.0 | V2.1 |
|---|---|
| `J1` 电源输入（2P） | 删除 → `VBUS_IN` / `PGND` 悬空引出 |
| `J2` 三相输出（3P） | 删除 → `PH_A` / `PH_B` / `PH_C` 悬空引出 |
| `J3` 控制-PWM（2×8） | 删除 → 6 个 `PWM_*_IN` 悬空引出 |
| `J4` 控制-采样（2×8） | 删除 → `VS_A/B/C`、`VN_SENSE`、`VBUS_SENSE`、`ISENSE_P/N`、`EN` 悬空引出 |
| `JP1` EN 选择跳线（3P） | 删除 → `EN_H` 与 `EN` 两个网络悬空引出，**外部短接二者 ≡ 原「1–2 短接」** |

**动机**：导入嘉立创EDA后连接器符号找不到对应封装；接口形式应由使用者自行决定。

**元件规模**：96 → **91 个位号**；网络仍 51 个；**22 个对外接口网络**（其中 8 个是单成员纯接线点：
`VBUS_IN`、6 个 `PWM_*_IN`、`EN_H`）。

⚠️ **新增的接线约束**：`EN_H` 与 `EN` 必须短接（或把 `EN` 接到高电平 / MCU 控制脚），
否则 `R16` 把 `EN` 拉低 → 降压不启动 → 整板无 12 V。

**封装可用性**：91 个位号中，89 个的封装名直接沿用你原工程或立创标准命名；
只有 **`F1`（保险丝，原占位 `Fuse_1206` → 改 `F1206`）** 与 **`D4`（SMB TVS）** 是我自造的，
需在立创中确认——详见 `03_审核/封装与接口对照表.md` §二。

**§9.1 的 JP1 章节作废**（跳线已取消），但其中"高电平源不能取 VCC(12V)"的结论仍然成立，
现已体现为：`R15` 从 `VCC_BUS` 取电产生 `EN_H`。

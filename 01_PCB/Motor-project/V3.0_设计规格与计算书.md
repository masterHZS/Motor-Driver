## ⚠️ 2026-09-14 决定性修订：母线窗口收窄为 **4S 专用（12.0 – 16.8 V）**

> **用户决定（2026-09-14）**：**本板只支持 4S，保留 12 V 栅压轨**，不支持 3S。
>
> **原因（审核发现，见 `03_审核/V3.0_原理图最终审核报告.md` §4）**：
> `XL7005A` 是**降压（buck）** 拓扑，`Vout < Vin` 是硬约束。要把 `VCC` 稳在 **12.075 V**
> （`1.25 × (1 + 8.66k/1k)`），最低母线需求为：
>
> | 依据（官方数据手册） | 所需最低母线 |
> |---|---|
> | Rev 1.9 最小压降 **2 V** | **≥ 14.1 V** |
> | Rev 1.9 最大占空比 **90 %** | ≥ 13.4 V |
> | Rev 1.0 最小压降 1 V | ≥ 13.1 V |
>
> 而 **3S 满充只有 12.6 V** —— 整个 3S 区间（9.0–12.6 V）都达不到。因此原
> §6.1「输入范围 5–80 V ⇒ 9.0–16.8 V 全范围覆盖」的写法是**把「芯片输入额定范围」
> 当成了「输出电压可达范围」**，结论不成立。
>
> **本修订同时废止**：原 §8「母线适用范围 9.0–16.8 V 全范围，3S/4S 都可用」的说法。
>
> **实际行为（供固件与测试参考）**：4S 母线在 **≳13.5–14 V** 以上可稳出 12 V；
> 低于该值 VCC 会**跟随母线跌落**（降压器天然行为，不会损坏，但栅压下降）。
> 因此固件应把**欠压保护门限设在 ≥ 13.5 V**，而不是原来的 9.0 V。
>
> **如需支持 3S**：把 `R10` 由 8.66 kΩ 改为 **6.8 kΩ**（`Vout ≈ 9.75 V`），
> 代价是 MOSFET 栅压从 12 V 降到 ~9.75 V、自举约 8.75 V —— 需实测 FD6288T 的
> UVLO 阈值并复核 `Rds(on)` 引起的导通损耗。**本次不做。**

### 1.3 载波与 RC 相移

一级 RC 截止 17 kHz（沿用已验证的 1 nF 网络）：

```
p=2: 相移 = arctan(487 / 17 000) = 1.64° 电角度
p=3: 相移 = arctan(730 / 17 000) = 2.46° 电角度
```

- 六步换向的换相点在过零后 **30°** → 1.64° 只占换相步的 **5.5 %**（p=3 时 8.2 %）
- **仍需固件补偿**，但比原设计的 3.23° 好很多
- 若想更小：一级滤波电容从 1 nF 降到 **330 pF**（fc = 51.5 kHz）→ p=2 相移降到 **0.54°**

## 2. 相电压采集网络（本次核心）

### 2.1 分压比

要求母线最高 16.8 V（+ 泵升裕量后按 20 V）时分压输出 ≤ ADC 参考 2.5 V 的 90 %：

```
k ≤ 2.5 × 0.9 / 20 = 0.1125
```

**沿用 `R_top = 150 kΩ` / `R_bot = 10 kΩ`** → `k = 10/160 = 0.0625`

| 母线 | AIN 读数（@Vref = 2.5 V） | 占满量程 |
|---|---|---|
| 9.0 V | 0.563 V | 22.5 % |
| 12.0 V | 0.750 V | 30.0 % |
| 16.8 V | **1.050 V** | **42.0 %** |
| 20.0 V（泵升） | 1.250 V | 50.0 % ✓ |

**分辨率核算**（12 bit / 2.5 V）：

```
1 LSB = 2.5 / 4096 = 0.610 mV  →  折算到母线 = 0.610 mV / 0.0625 = 9.8 mV
在 16.8 V 时相对误差 = 9.8 mV / 16.8 V = 0.058 %   ✓ 足够
```

**功耗**：`@16.8 V = (16.8−1.05)²/150k = 1.65 mW` ✓（0603 额定 100 mW，余量 60×）

**精度**：三相必须用 **±1 % 同批次**电阻，保证分压比一致（比值不一致会直接变成过零判定的共模误差）。

### 2.2 一级 RC 滤波（**沿用**）

```
τ = (150k ∥ 10k) × C = 9.375 kΩ × 1 nF = 9.4 µs  →  fc = 17.0 kHz
```

- 作用：压制 20 kHz PWM 载波与开关尖峰
- 相移 3.23° → 见 §1.3，固件补偿
- **三相的 R、C 必须完全相同**（同批次），否则引入不对称

### 2.3 虚拟中性点（**保留硬件网络，同时进 ADC 作诊断**）

**做法**：从三个已分压的节点 `A_DIV / B_DIV / C_DIV` 各经 `R_n = 100 kΩ` 星接到 `VN`。

```
VN = (A_DIV + B_DIV + C_DIV)/3 = k × (V_A + V_B + V_C)/3  ✓
```

**负载效应与共模抵消证明**（本设计成立的关键）：

```
单相分压节点的等效负载 = R_n + (R_n ∥ R_n) = 100k + 50k = 150 kΩ
与 R_bot 并联 → 150k ∥ 10k = 9.375 kΩ
实际分压比 k' = 9.375 / (150 + 9.375) = 0.0588   （标称 0.0625 的 94 %）
16.8 V × 0.0588 = 0.988 V  ✓ < 2.5 V
```

- 三通道的 `R_top`/`R_bot`/`R_n` **完全相同** → 缩放因子 `k'` 对三相**完全一致**
- 固件做 `V_phase` vs `V_neutral` 比较时，**相同缩放因子自动抵消** → 不影响过零判定 ✓

**时间常数对称性**（最容易漏的一步）：

| 节点 | 等效源阻抗 | 配的电容 | 截止频率 |
|---|---|---|---|
| `A_DIV / B_DIV / C_DIV` | 9.375 kΩ | **1 nF** | 17.0 kHz |
| **`VN` 节点** | `3 × (9.375k + 100k)` 并联 = **36.5 kΩ** | **270 pF** | 17.0 kHz |

> `C_VN = 1/(2π × 17k × 36.5k) = 256 pF` → 取 **270 pF**
> 🔴 **VN 不配电容（或配成 1 nF）会让中性点比三相快/慢一个数量级 → 中性点滞后 → 过零点系统性偏移。**
> **这一步必须做，是最容易漏的设计点。**

### 2.4 二级 RC（送 AIN）

每路串 **1 kΩ** + 对 AGND 并 **1 nF** → `τ = 1 µs`，`fc = 159 kHz`

- 限流保护 MCU 引脚、与走线电感解耦
- **4 路（A/B/C/VN）必须完全同构**，否则引入新的不对称误差

### 2.5 与 MCU 的接口约束（供固件设计）

| 约束 | 说明 | 依据 |
|---|---|---|
| ADC 通道 | `A_DIV→AIN0(P24)`、`B_DIV→AIN4(P34)`、`C_DIV→AIN7(P01)`、`I_SENSE→AIN8(P02)` | 引脚分配表 |
| ADC 参考 | **必须选内部 2.5 V**（`RefVolSelInBgr2p5`），**不要用 AVDD** | `adc.h` `en_adc_ref_vol_sel_t` |
| 采样模式 | **`AdcScanMode` 扫描 4 通道**（3 相电压 + 母线电流） | `adc.h` `en_adc_op_mode_t` |
| 硬件触发 | **ADT 下溢/上溢/计数匹配 A~D 触发 ADC**（`AdcTrigTimer4/5/6`） | `adt.h:532-540` |
| 采样时刻 | 固定在 PWM 周期中点（中心对齐模式下 = 计数谷点），**避开开关瞬间** | — |
| 消隐 | 换相后必须消隐（躲续流二极管导通期），建议 **2–5 µs** | — |
| 启动 | BEMF ∝ 转速 → 静止时为零 → **必须三段式启动**（预定位 → 开环加速 → 切闭环） | — |

## 3. 主控 HC32F005 接口设计

### 3.1 芯片能力对照（官方数据手册 Rev3.00 + DDL 核实）

| 需求 | 芯片能力 | 结论 |
|---|---|---|
| 6 路互补 PWM | **3 颗 ADT（TIM4/5/6）各 2 通道** | ✓ 三颗硬件同步 `Adt_SwSyncStart()` |
| 硬件死区 | `DTUAR`/`DTDAR` 各 16 bit，可上升/下降独立 | ✓ 固件不需插死区 |
| 硬件刹车 | **VC 比较器 → `VcOutBrake`（强制输出无效条件 0）** | ✓ µs 级、不经软件 |
| 过零检测 | **9 路外部 ADC**，扫描模式 + ADT 触发 | ✓ 用 4 路 |
| 过流检测 | ADC + VC0 比较器 + 6 位 DAC 阈值 | ✓ |
| 主频 | 内部 RCH 24 MHz（**本设计不用外部晶振**） | ⚠️ 需 ADC 基准校准 |
| 资源 | Flash 32 KB / RAM 4 KB | ⚠️ 固件要精打细算，**避免浮点库** |

### 3.2 时钟方案（关键决策）

**不用外部晶振**（引脚不够），用内部 RCH：

```
Sysctrl_SetRCHTrim(SysctrlRchFreq24MHz);   // 24 MHz
Sysctrl_SetHCLKDiv(SysctrlHclkDiv1);       // HCLK = 24 MHz
Sysctrl_SetPCLKDiv(SysctrlPclkDiv1);       // PCLK = 24 MHz
```

| 影响 | 数值 | 缓解 |
|---|---|---|
| PWM 周期分辨率 | 24 MHz / 20 kHz = **1200 计数** | ✓ 足够（占空比分辨率 0.083 %） |
| 内部 RC 精度 | 数据手册标称 ±2.5 %（全温度电压） | ⚠️ 转速显示误差 ≤2.5 %；**换相时机用 ADC 过零事件自同步，不依赖绝对时钟** ✓ |
| 死区精度 | 死区计数值随主频漂移 | 死区按**最小可用值**设定，漂移方向只影响效率不影响安全 |

> **结论**：无感六步换向的换相时刻由**过零事件 + 30° 延时**决定，延时用定时器计数实现，
> **不需要绝对准确的时钟**（自同步）。±2.5 % 的 RC 误差只影响"转速读数"的精度，不影响换相正确性。**可以接受。**

### 3.3 三对互补 PWM 分配

| 相 | 高边 HINn | 低边 LINn | 定时器 |
|---|---|---|---|
| **A** | P23 → FD6288T.1 | P15 → FD6288T.4 | **TIM4**（CHA 高 / CHB 低） |
| **B** | P26 → FD6288T.2 | P33 → FD6288T.5 | **TIM5**（**CHB 高 / CHA 低** ⚠️反的） |
| **C** | P36 → FD6288T.3 | P32 → FD6288T.6 | **TIM6**（CHA 高 / CHB 低） |

🔴 **B 相的 CHA/CHB 与 A/C 相反** —— 初始化时 `PCONR.STACA/STACB`、`PERC/CMPC` 必须相反配置。
**这是本设计最容易写错的一处。**

### 3.4 互补输出初始化陷阱（必读）

引自 `AN_ADVANCED_TIMER` §"硬件死区功能设定"：

```
① GCMAR（CHA 比较基准）初始必须 < PERAR（周期值）
② GCMCR 必须初始化为 0xFFFF
③ 初始 IO 为高阻，需把 PIN 切到 ADT 功能后才开始输出
④ PCONR.STACA = 0（CHA 起始低）、STACB = 1（CHB 起始高）
```

不遵守 ①② 会导致 **CHB 后续输出错误波形 → 上下桥直通**。

### 3.5 过流保护链路（**注意：无硬件刹车，见 §5.3**）

```
分流电阻 R32 → INA181A2 差分放大 → ADC / P02(AIN8) → 固件判阈值 → 降占空比 / 停机
                                   ↑
                        FD6288T 自带 UVP + SCP 兜底
```

> 🔴 **本版没有 VC 硬件刹车**（`VcOutBrake`）—— 因为 16 个 GPIO 全部占用，
> **没有空闲引脚接 VC 比较器正端**。详见 §5.3。这是引脚预算带来的明确妥协。

### 3.6 引脚分配结论（已定稿，无未闭合项）

| 用途 | 引脚 | 数量 |
|---|---|---|
| 三相 6 路 PWM | P23、P15、P26、P33、P36、P32 | 6 |
| 相电压 ADC（过零） | P24(AIN0)、P34(AIN4)、P01(AIN7) | 3 |
| **母线电流 ADC** | **P02(AIN8)** | 1 |
| UART0_TX | P14 | 1 |
| SWD | P27、P31 | 2 |
| RESETB | P00 | 1 |
| 测试点/ISP 预留 | P03、P25、P35 | 3 |
| **合计** | | **16 / 16（全部用完）** |

**虚拟中性点（VN）的处理**：硬件电阻星网络**仍然保留**（对分压网络有平衡作用、降低共模噪声），
但 **VN 不接 ADC** —— 固件用 `V_N = (V_A + V_B + V_C)/3` **软算**。
这是无感六步换向的标准做法，精度完全够用（过零比较的是"悬空相 vs 中性点"的差值）。

> ✅ 用户已确认：**P02/AIN8 给母线电流**（限流是无感启动的必需项，否则堵转即炸管）。

### 4.2 损耗核算 @ 16.8 V / 8.8 A（最恶劣工况）

| 损耗项 | 计算 | 数值 |
|---|---|---|
| **导通损耗**（每管） | `I² × Rds(on) × D`，D ≈ 0.5（两管串联合成 100 %）<br>`8.8² × 5.3 mΩ × 0.5 = 205 mW` | **205 mW** |
| **开关损耗**（每管） | `½ × Vds × Id × (tr + tf) × f_sw`<br>`0.5 × 16.8 × 8.8 × (20+20) ns × 20 kHz = 59 mW` | **59 mW** |
| **栅极驱动损耗**（每管） | `Qg × Vgs × f_sw = 73 nC × 12 V × 20 kHz` | **17.5 mW** |
| 输出电容损耗（每管） | `½ × Coss × V² × f_sw`，Coss ≈ 400 pF → **1.1 mW** | 可忽略 |
| **单管总损耗** | `205 + 59 + 17.5 + 1.1` | **≈ 283 mW** |
| **6 管总损耗** | `6 × 283 mW` | **≈ 1.70 W** |
| **全板效率影响** | `1.70 / 90 = 1.9 %` | ⚠️ 偏高但可接受 |

**结温核算**（PDFN-8，Rθja ≈ 50 ℃/W，环境 50 ℃）：

```
Tj = 50 + 0.283 × 50 = 64 ℃
若 Rθja = 60 ℃/W → Tj = 50 + 17 = 67 ℃   ✓  仍远低于 125 ℃
```

> **结论：100 V 管在 16.8 V 母线上暖升约 +14~17 ℃，工程上安全，但已不宽裕。**
>
> ⚠️ **可选优化（不改也能工作）**：把 MOSFET 换成 **30 V 级逻辑电平管**（如 Rds(on) ≈ 2 mΩ、Qg ≈ 25 nC）：
> 单管损耗从 283 mW 降到约 **105 mW**，6 管从 1.70 W 降到 **0.63 W**，
> **省下约 1.07 W（效率 +1.2 %）、结温降到 55 ℃**。
> 若你后续想改，这是一个低风险的替换（封装同为 PDFN-8 5×6）。

**功率器件选型的最坏情况**（堵转 18 A）：

```
单管导通损耗 = 18² × 5.3 mΩ × 0.5 = 858 mW（毫秒级瞬态）
→ 靠 13 A 过流保护在 50 µs 内切断，瞬态热容足以吸收
```

### 5.1 分流电阻选型

**约束**：额定 **8.8 A**，过流 **13 A**，堵转瞬态可达 **18 A**。

| 候选 | 8.8 A 压降 | 13 A 压降 | 13 A 功耗 | 8.8 A 功耗 | 评价 |
|---|---|---|---|---|---|
| 1 mΩ / 2512 / 2 W | 8.8 mV | 13 mV | 0.17 W | 0.077 W | ❌ 信号太小，失调难控 |
| 2 mΩ / 2512 / 2 W | 17.6 mV | 26 mV | 0.34 W | 0.155 W | 折中 |
| **3 mΩ / 2512 / 2 W** | **26.4 mV** | **39 mV** | **0.507 W** | **0.232 W** | ★ **推荐** |
| 5 mΩ / 2512 / 2 W | 44 mV | 65 mV | 0.845 W | 0.387 W | 余量偏小 |

**选 3 mΩ / 2512 / 2 W**：

```
额定 8.8 A → 26.4 mV，功耗 0.232 W  （额定 2 W，余量 8.6×）✓
过流 13 A  → 39.0 mV，功耗 0.507 W  ✓
堵转 18 A  → 54.0 mV，功耗 0.972 W  （瞬态，毫秒级）✓
温升（2512，Rθja ≈ 56 ℃/W）@13 A = 0.507 × 56 = 28 ℃ ✓（环温 50 → 78 ℃，可接受）
                             @8.8 A = 0.232 × 56 = 13 ℃ ✓
```

⚠️ `3 mΩ × 8.8 A = 26.4 mV` 是**小信号**，放大器失调必须 < 0.5 mV（折算 0.17 A 误差）→ **必须用专用电流检测放大器**，见 §5.2。

> **若想降功耗**：改 **2 mΩ** → 过流功耗降到 0.34 W、温升 19 ℃，但 8.8 A 时只有 17.6 mV，
> 对放大器失调要求提高到 < 0.3 mV。**建议先用 3 mΩ**，实测噪声后再决定是否降到 2 mΩ。

**方案：专用电流检测放大器（推荐）**

### 5.3 过流保护：只有一级（软件限流）

| 级别 | 实现 | 响应 | 本版可用？ |
|---|---|---|---|
| ① **VC 硬件刹车（µs 级）** | 放大输出 → **VC0 正端** → `VcOutBrake` 强制 HIN/LIN 全无效 | 纯硬件 | ❌ **引脚不够，无法实现** |
| ② **软件限流（ms 级）** | ADC 扫描读电流 → 超阈值降占空比 / 停机 | 软件 | ✓ 本版方案 |
| ③ **FD6288T 内置 SCP** | 驱动芯片自带的短路保护 | 硬件 | ✓ 兜底 |

> 🔴 **为什么没有硬件刹车**：VC0 正端只能选 P23 / P25 / P32 / P33 / P34 / P35 / P36 / P01，
> 而 V3.0 里这些脚**全部被 PWM 或相电压 ADC 占用**（见 `HC32F005_引脚分配.md`）。
>
> **后果**：过流响应从 µs 级退化为"ADC 采样周期 + 软件判断"级（约 50–200 µs）。
> 在这段时间里 18 A 堵转电流会冲击 MOSFET（单管瞬时 858 mW）。**缓解措施**：
> - 靠 FD6288T 的 **SCP** 兜底（µs 级硬件保护，但不含可编程阈值）
> - 固件把电流采样放在**每个 PWM 周期**（20 kHz → 50 µs 一次），判断后**立即**清 PWM
> - 软件消隐与滤波不能增加延迟
>
> **要拿到真正的硬件刹车，只有两条路**：① 换 **QFN24 封装**多出 IO；② 放弃一路相电压 ADC，
> 改用 **VC 比较器**（但只有 2 个 VC，做不了三相，必须 ADC 兜底第三相）。
>
> ✅ **用户已确认接受本妥协。**

### 6.2 EN / UVLO

> ## ⛔ 本节结论已作废 —— EN 极性搞反了（2026-09-13 由立创数据手册查实）
>
> **立创商城 XL7005A（C50848）官方数据手册原文**（已缓存 `06_参考资料/芯片知识库/_datasheet/DS_XL7005A_立创.pdf`）：
>
> | 出处 | 原文 |
> |---|---|
> | Table 1 Pin Description | 「Enable Pin. **Drive EN pin low to turn on the device, drive it high to turn it off. Floating is default low.**」 |
> | Electrical Characteristics (DC) | `EN Pin Threshold VEN`：**High (Regulator OFF) = 1.6 V**；**Low (Regulator ON) = 0.8 V** |
> | 同上 | `EN Pin Input Leakage IH: VEN=2.5V (OFF)`；`IL: VEN=0.5V (ON)` |
>
> → **XL7005A 的 EN 是「低有效」**：EN 低 = 导通，EN 高 = 关断，**悬空 = 默认低 = 导通**。
>
> ### 两个后果
>
> **① V3.0 本节的 UVLO 电路方向是错的。**
> `VCC_BUS —R15(130k)— EN —R16(15k)— PGND` 会让 EN **随母线升高而升高**：
> 母线 > 15.5 V 时 EN > 1.6 V → **降压被关断**。而 4S 正常工况是 14–16.8 V → **板子根本不工作**。
>
> **② V2 时代的「P0 致命缺陷 ②：U2.EN 直接接地」是误判。**
> EN 接地 = 0 V = **Regulator ON** —— 原设计者接的是**对的**，那是「永远使能」的合法用法。
> 早期分析（`03_审核/修复方案.md` F2、`分析报告.md` ②）按「高有效」推断，得出了相反的结论，**并在 V3.0 中引入了真正的缺陷**。
>
> ### 已决定：方案 A（用户 2026-09-13 选定）
> **删除 `R15`，`EN` 经 `R16 = 15 kΩ` 接 `PGND` = 永远使能**；欠压保护改由固件读 `AIN_VBUS`(P01) 实现。
> 详细设计、校核与两次错误的复盘见本节下方正文。
>
> 其余备选（未采用）：**B** 加 NPN 反相做硬件 UVLO（门限受 `Vbe` 温漂 ±10 %）；**C** 换带精密使能的降压芯片。
>
> ---


**电路形式**（V3.0 终版 · **方案 A**）：

```
U2.EN(4) ──┬── R16 = 15 kΩ ── PGND     ← EN 经下拉电阻接地 = 恒 0 V
           └── C29 = 100 nF ── PGND     ← 滤波 / 上电软化
                                  （R15 = 130 kΩ 已删除）
```

- `EN` **低有效**（立创数据手册实测，见上方 ⛔ 框）：`EN ≤ 0.8 V → 导通`；`EN ≥ 1.6 V → 关断`；**悬空 = 默认低 = 导通**
- 方案 A 让 **EN 恒为 0 V → XL7005A 永远使能**，母线一到就出 12 V，不存在门限不确定问题
- 保留下拉电阻 `R16 = 15 kΩ`（而非直接短接）：明确电平、抑制噪声、将来若要加硬件 UVLO 有改板余地
- `C29 = 100 nF` 与 R16 组成 `τ = 1.5 ms` 的 RC，软化上电沿

| 项目 | 值 | 校核 |
|---|---|---|
| EN 上的压降 | `I_leak(最大 10 µA) × R16(15 kΩ) = 0.15 V` | `0.15 V << 0.8 V` 导通门限 ✓ |
| 母线适用范围 | **12.0 – 16.8 V（4S 专用）** | ⚠️ 2026-09-14 修订：**不支持 3S** —— 12 V 轨需 ≥13.4–14.1 V 母线（见卷首修订）；固件欠压门限 ≥13.5 V |
| 静态电流影响 | EN 恒 0 V → 无额外分压电流损耗 | 优于原分压方案 ✓ |
| 代价 | **无硬件母线欠压保护** | 见下方「软 UVLO 由固件实现」 |

> ★ **欠压保护改由固件实现**：母线电压经 `R30/R31` 分压后已接到 **`AIN_VBUS`（P01）**，
> 固件可自行判定欠压并停止换相 —— 比硬件 UVLO 更灵活（门限可配置、可带迟滞与恢复策略），且不增加任何元件。

#### ★★ 缺陷复盘：这一处连续犯了两个方向相反的错误

**错误一（V2 时代 — 误判了正确的设计）**
V2 原始原理图把 `U2.EN(4)` 接在 GND 上。早期分析（`03_审核/修复方案.md` F2、`分析报告.md` ②）
**默认 EN 是高有效**，判定这是「P0 级致命缺陷：降压被永久关断 → 整板不工作」。
**实际 EN 是低有效，接地 = 永远导通 —— 原设计者是对的。**

**错误二（V3.0 — 把对的改成了错的）**
V3.0 依据上述误判，"修"成 `VCC_BUS —R15— EN —R16— GND` 分压：
母线超过约 15.5 V 时 EN 被抬到 1.6 V 以上 → **在 4S 正常工况（14–16.8 V）下反而关断降压**。
同时把分压中点单独命名为 `EN_H` 并留作"人工短接"，而板上没有任何跳线能完成它
（由 KiCad ERC 的 `isolated_pin_label` 抓出：`EN_H` 只挂了一个电阻脚 `R15.2`）。

**本次最终修正**：删除 `R15`；`EN` 经 `R16 = 15 kΩ` 接 `PGND`；`C29 = 100 nF` 保留作滤波；
`INTERFACE_NETS` 中不登记 `EN`。

> **教训**：器件的**极性**（高有效 / 低有效）必须查**官方数据手册原文**，
> 不能靠"常规接法"或"同名器件的习惯"推断。方向推断错，会把正确的设计"修"成错误的，
> 而且改完之后**看起来同样合理**，只有查原文才能发现。
> 数据手册已缓存：`06_参考资料/芯片知识库/_datasheet/DS_XL7005A_立创.pdf`（从立创 C50848 商品页下载）。

`HC32F005` 运行态 `IDD` 2.67 mA typ / 3.40 mA max（24 MHz，全外设时钟开）
＋ `INA181` 静态 260 µA max ≈ **3–4 mA**。
（注意：§6.1 里的 11 mA 是 **12 V 轨** 的负载，不是 3.3 V 轨。）

**结论与约束**：

1. 按现有负载**不构成热问题**（`Tj ≈ 53 ℃`），**本次不改硬件**。
2. ⚠️ **硬性约束：3.3 V 轨负载 ≤ 30 mA。** 超过后 `Tj` 迅速逼近上限；
   到 100 mA 时 `Tj ≈ 129 ℃`，会触发过温保护 → 3.3 V 跌落 → MCU 复位。
   **任何"在 3.3 V 上外挂东西"的想法都必须先复核这条。**
3. ⚠️ **输入绝对最大只有 15 V**，而输入是 12.075 V —— 余量仅 2.9 V。
   正常工况无碍（`L1` 的 47 µH + `C40/C41` 会吸收瞬态），
   但**若 TVS 在母线上动作（钳位 53.3 V），不要指望这级能扛**。
   这也是建议换 `SMBJ20A`（把钳位压到 32.4 V）的理由之一。
4. 若将来负载必然增大：**加一级 5 V 中间轨**（第二颗 buck 或 AMS1117-5.0），
   100 mA 时 `P_D` 从 878 mW 降到 **170 mW**；或直接改用 3.3 V 同步降压。
5. PCB：`U4` 的散热 tab（= `VOUT`）需要**足够铺铜**；
   本核算按 θJA=90 ℃/W（保守值）取数，铺铜好则更宽裕。

**如需支持 3S 时的额外影响**（本次已决定不支持，仅备查）：
3S 下 VCC 会跌到 ~10.6 V，`P_D` 降到约 64 mW，**LDO 反而更凉**；
但 `U4` 的输入来自跌落的母线，压差更小 → 更安全。即 **3S 的瓶颈在栅驱动而不在 LDO**。

# HC32F072 级联驱动 FD6288T（第一阶段）

## 链路

```text
HostSoftware
  -> DAPLink UART (虚拟 COM, 9600-8N1)
  -> F072_Bridge (透明字节转发)
  -> F072_MotorCtrl (Modbus-RTU 地址 1, 115200-8N1)
  -> V1.0 FD6288T
  -> 2216-730KV 三相无刷泵
```

第一阶段没有使用反电动势、相电压、虚拟中性点或电流反馈。它是台架开环六步运行，不是闭环稳速控制。

## 接线表

### 1. DAPLink 到第一颗 F072

| DAPLink 信号 | F072#1 | 说明 |
|---|---|---|
| UART TX | PA10，脚31，H2-28 | DAPLink 发送到 F072 |
| UART RX | PA9，脚30，H2-26 | F072 回传；PA9 板载 LED 可能闪烁 |
| GND | GND，H2-11/23/24 | 必须共地 |
| SWDIO/SWCLK/GND | 板上 SWD 排针 | 烧录时使用 |

### 2. 两颗 F072 之间

| F072#1 | F072#2 | 说明 |
|---|---|---|
| PA2，脚12，H2-4 (TX) | F005 P27/RX | 下游 UART1 TX，115200-8N1 |
| PA3，脚13 (RX) | F005 P14/TX | 下游 UART1 RX，115200-8N1 |
| GND | GND | 两块板必须共地 |

两块核心板可分别由 USB/5 V 供电。除非已经确认供电方案，否则不要把两路 3.3 V 或 5 V 输出直接并联。

### 3. 第二颗 F072 到 V1.0 FD6288T

| F072#2 引脚 | FD6288T | 驱动板网络 | 功能 |
|---|---|---|---|
| PB2，脚20，H2-12 | U1 脚1 | HIN1 | A 相高边 |
| PA7，脚17，H2-7 | U1 脚4 | LIN1 | A 相低边 |
| PA4，脚14，H2-6 | U1 脚2 | HIN2 | B 相高边 |
| PB0，脚18，H2-10 | U1 脚5 | LIN2 | B 相低边 |
| PB12，脚25，H2-17 | U1 脚3 | HIN3 | C 相高边 |
| PB1，脚19，H2-9 | U1 脚6 | LIN3 | C 相低边 |
| GND | U1 脚8/COM 与功率地星点 | GND | 逻辑地参考 |

V1.0 板没有防护连接器，建议在 FD6288T 输入附近增加：

- 六路各串 `100 Ω`；
- 六路各对 GND 加 `10 kΩ` 下拉；
- 逻辑地只在 FD6288T COM/功率地星点汇合；
- 信号线远离 `VCC_BUS`、三相输出和自举节点。

### 4. 功率与电机

- 4S 电池正极：`VCC_BUS`，经 15 A 慢熔保险丝。
- 4S 电池负极：`PGND`。
- 电机三相：`PH_A`、`PH_B`、`PH_C`，顺序不确定时交换任意两根相线即可反向。
- V1.0 的 XL7005A `EN` 为低有效；按参考图接低即输出 12 V，给 FD6288T VCC 和自举网络供电。
- 不要把 12 V 直接接至任何 F072 GPIO。
- 首次上电必须使用 `12.0～16.8 V` 电源并把限流设为 `5 A`。

## 控制协议

HostSoftware 原协议保持不变：

- 读：`01 03 00 00 00 0A + CRC`
- 启停：`01 06 00 01 00 01/00 + CRC`
- 油门：`01 06 00 02 00 00..64 + CRC`
- PWM 频率：`01 06 00 03 03 E8..4E 20 + CRC`

第二颗 F072 寄存器：

| 地址 | 含义 |
|---|---|
| `0x0000` | 运行状态（1 运行、0 停止/故障） |
| `0x0001` | 启停请求 |
| `0x0002` | 目标油门 0..100 |
| `0x0003` | PWM 频率 1000..20000 Hz |
| `0x0004` | 实际占空比，最大 30% |
| `0x0005` | 故障位：0x0001 非法命令，0x0002 通信超时 |
| `0x0006` | 当前电换相频率（Hz） |
| `0x0007` | 固件版本 0x0100 |
| `0x0008` | 通信错误计数 |
| `0x0009` | 通信成功计数 |

## 安全行为

- 启动时先预定位 200 ms，再以 10 Hz 电频率起步、100 Hz/s 斜坡上升，最高 500 Hz 电频率。
- 油门只控制高边 PWM 占空比，实际占空比硬限制为 30%。
- 通信超过 1 秒无有效请求时立即关断六路输出并置故障。
- 非法命令、非法值或未支持功能码会关断输出并置故障。
- 清除故障后必须重新写入启动命令，电机不会自动恢复。

## 构建与烧录

两个固件工程均支持：

```powershell
.\build.ps1
.\build.ps1 -Flash
```

若 `arm-none-eabi-gcc` 不在 PATH：

```powershell
.\build.ps1 -ToolchainBin "C:\path\to\arm-none-eabi\bin"
```

输出：

```text
build/hc32f072.elf
build/hc32f072.hex
build/hc32f072.bin
```

使用 DAPLink/pyOCD 时，先烧录 `F072_Bridge`，再烧录 `F072_MotorCtrl`。运行 HostSoftware 时，DAPLink 的虚拟串口必须连接到第一颗 F072 的 PA9/PA10。

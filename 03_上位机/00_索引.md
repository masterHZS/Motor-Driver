
# 03_上位机 索引

标签：`[主软件]` `[源码]` `[发布版]` `[Modbus主站]`

## 推荐查看顺序

1. `HostSoftware/README.md`：构建、运行、通信和界面说明。
2. `HostSoftware/src/CCommManager.*`：Modbus-RTU 主站、串口与轮询。
3. `HostSoftware/qml/Main.qml`：主界面与控制按钮绑定。
4. `HostSoftware/qml/ThrottleControl.qml`：油门推杆控件。
5. `release/HostSoftware/`：无需重新编译的直接运行版本。

## 分类

| 目录 | 标签 | 说明 |
|---|---|---|
| `HostSoftware/` | 源码 | Qt 6 + QML 工程、源码、构建脚本、Git |
| `release/HostSoftware/` | 发布版 | EXE、Qt DLL、运行时依赖 |
| `HostSoftware/build*/` | 可重建 | CMake 中间产物，不进入资料归档 |

## 通信顺序

```text
打开串口(9600-8N1)
-> 250 ms 周期读 0x0000..0x0009
-> 油门推杆写 0x0002
-> 启动/停车写 0x0001
```

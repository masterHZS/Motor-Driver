FD6288  250V Three-phase Gate Driver 
1 System Introduction 
1.1 Overview 
FD6288 is an integrated circuit  (IC) that 
integrates t hree independent half -bridge gate 
drivers. It is specially designed for high-voltage and 
high-speed drive MOSFETs and operates up to 
+250V . 
FD6288 supports under-voltage lockout (UVLO) 
feature, protecting the power device from operating 
with insufficient voltage. 
FD6288 also provides cross-conduction 
prevention and deadtime insertion  to effectively 
protect the power IC and prevent both MOSFETs of 
each half-bridge from switching on at the same time. 
FD6288 has built-in input signal filtering  
module to avoid input noise interference. 
1.2 Packages 
 
 
 
 
 
TSSOP-20                QFN-24 
 
 
 
 
 
 
 
 
 
1.3 Features 
◼ Fully operational to +250V 
◼ Power supply: 5V to 20V 
◼ Three independent half-bridge drivers 
◼ Output current: +1.5A/-1.8A 
◼ 3.3V and 5V logic input compatible 
◼ VCC/VBS UVLO 
◼ Cross-conduction prevention logic 
◼ 200ns deadtime 
◼ Built-in input filtering module 
◼ Matched propagation delay for high-side and 
low-side channels 
◼ Outputs in phase with inputs 
1.4 Applications 
Motor drivers

# EasyEDA 导出与布局资料

本目录集中保存从 EasyEDA / 嘉立创工程导出的布局数据、布线 JSON、脚本、图片和源工程。

- `easyeda_*.json`：元件、网络、模块位置、布线等中间数据。
- `easyeda_local_router.py`、`apply_module_wiring.ps1`：生成/布线辅助脚本。
- `layout-*.png`、`motor-driver-V3-*.png`：版面审核图。
- `motor-driver.eprj2`：嘉立创源工程备份。
- `SCH_Schematic1_2026-09-09.pdf`：原理图导出 PDF。

长期结论请写入 `06_参考资料/芯片知识库/` 或 `01_PCB/03_审核/`，不要把仅用于一次布置的临时 JSON 当作权威设计源。

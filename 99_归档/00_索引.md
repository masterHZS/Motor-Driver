# 99_归档 索引

标签：`[历史]` `[不再维护]` `[待评估删除]`

## 推荐处理顺序

1. 先确认是否被当前 PCB、F005、F072 或 HostSoftware 引用。
2. 不能被确认归属的固件只保留，不继续修改。
3. 已冻结的 PCB 源工程和旧版备份集中保留。
4. 确认无追溯价值后可整体删除本目录。

一、基本要求
项目名：HostSoftware
项目根目录：E:/Project/ECU/HostSoftware
开发环境：vscode集成Qt6.8.3/C++/qml
编译环境：cmake+Qt6.8.3（MSVC2022-64bit）
代码命名规则：按照Qt通用规范使用大、小驼峰命名，类名加前缀”C”，成员变量加前缀”m_”，示例：CMyClassName，m_memberName。
工具链安装位置见：ToolChain.docx文件

二、项目需求
该项目为ECU的上位机软件，目前需要做一个界面，UI中的各按钮功能暂空，UI效果使用qml实现。界面整体为左中右的水平布局，左中右三个区域内部为垂直布局，左侧为连接属性和状态机控制。
中间显示下位机的各项状态参数。右侧为其他功能界面。左、右部分各占整个界面的1/4。中间部分占1/2。窗口大小变更时布局不能乱。
以下是各区域的详细布局描述：
各区域内部版块之间使用边框隔开，边框内不需要注明版块名。
1. 左侧连接属性和状态机控制区域
最上方为通信版块，横向排列了一组通信设置控件：包含“COM口选择”（如COM1）、“波特率”（如9600）、“数据位”（如2）的下拉菜单。
通信板块下方为控制版块：包含两个控制按钮和一个关闭按钮，初始显示两个控制按钮，分别为“转速控制”和“油门控制”，这两个按钮为红色背景，在任何一个被点击之后，两个按钮都会消失并在第一个按钮的位置出现一个关闭控制的按钮，关闭控制的按钮在点击后同样会消失并复现两个控制按钮，关闭按钮背景为绿色。
控制版块下方为三个大按钮：“启动”按钮、“停车/散热”按钮、“紧急停车”按钮，这三个按钮跟后续的状态机控制有关，三种状态同时有且只能有一种状态生效，初始为“紧急停车”，通过点击按钮切换，按钮生效时背景为绿色，不生效时背景为灰色。
2. 中间：数据监控区域
最上方为引擎状态区域：横向显示引擎状态和故障码，例：“引擎状态：故障”、“故障码：001，测试故障”
引擎状态区域下方为转速、温度区域：横向排布三个控件，包含一个转速表和两个温度计。转速表显示下位机电机转速，转速表上方2/3的扇形区域为指针区域，量程0-70000，下方1/3为LCD数字显示区域用于数字形式显示转速。第一个温度计为排气温，量程0-1000，第二个温度计为ECU温度，量程0.0-100.0。
转速、温度区域下方为详细参数矩阵，
矩阵参数及示例分别为：
“当前油泵电压：0.0”、“控制电压：0.0”、“动力电压：0.0”、“电流：0.0”、“油泵最大电压：0.0”、“油泵点火电压：0.0”、“转速加速系数：0”、“启动时间：0”、“最高转速：0”、“怠速转速：0”。
3. 右侧：油门控制组件
上方为参数设置按钮：点击之后会新打开一个参数页窗口，该页面显示当前的参数值并且可以手动输入参数和保存，参数页标题为“参数设置（请谨慎更改）”，主体为垂直布局显示各参数的参数名、当前值、数值修改框（初始值显示为当前值，可修改），示例：参数1 1.2 0.0，右下角为“应用”、“完成”、“取消”按钮。“应用”按钮初始使能状态为false，字体显示灰色，当有参数发生修改时该按钮使能并且字体颜色恢复正常，此时点击“应用”按钮会弹出“确认”的提示框，点击确认后输入框中的数值会更新值当前值中并保存；点击“完成”按钮时会先“应用”然后退出，该按钮点击时同“应用”按钮一样当有参数发生修改时会有相同提示框出现；点击“取消”按钮时不“应用”就退出参数设置界面，界面中的数据不保存。该功能中的各个参数保存在当前文件夹中的ParaSetttings.ini中。
参数设置按钮下方为功能测试按钮：点击之后会新打开一个功能测试窗口，该窗口主体为功能测试的所有按钮，包括“测试主油路电磁阀”、“测试热火头”、“燃油清零”、“油泵排除空气”、“测试点火电磁阀”、“测试启动电机”、“推力清零”、“测试油泵(短时)”、“测试油泵(长时)”、“关闭油泵”，页面右下角为”返回“按钮，”返回“按钮点击后会关闭该窗口。
上述两个按钮弹出新窗口时均无法直接聚焦到主窗口，需先关闭新窗口才能聚焦到主窗口。
功能测试按钮下方为油门推杆组件：组件包含“推杆轨道”和“推杆”两部分，“推杆”在“推杆轨道 ”上方，初始位于“推杆轨道”最底部，并且可以在“推杆轨道”中上下移动，推杆需醒目。推杆上显示当前油门百分比“油门：d%”，d%为“推杆”在“推杆轨道”中自下向上的位置进度，区间0%-100%，“推杆轨道”中“推杆”已行进的部分背景和未行进的部分背景通过绿色、灰色做区分。推杆组件上方使用label注明该组件名称“油门推杆”。推杆组件下方使用LCD显示油门百分比。
油门推杆组件下方为气压表：气压表上方为label注明组件名字“气压（kPa）”，下方为LCD显示当前气压。

三、注意事项
1.转速表和温度计控件样式可以尝试找github上现有的开源项目做参考。
2.qml控件各按钮的坐标定位请核查，避免由于定位错误导致按钮不生效。
